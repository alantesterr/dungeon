# План: «💻 Практика C++» — Builder точь-в-точь и обучение с нуля

Статус: **ждёт обновления лимита** (план утверждён автором 26.11.2026). Делать по шагам, после каждого шага — проверка и заливка.

## 0. Эталон — настоящий C++Builder 6 на компьютере автора
- Открыть настоящий Builder 6 (`C++Builder 6` в Пуске, разрешение уже давали) через управление компьютером.
- Снять каждое окно и меню: главное окно, Object Inspector (Properties/Events), Object TreeView, редактор с ClassExplorer,
  форма с сеткой, меню File/Edit/Search/View/Project/Run/Component/Database/Tools/Window/Help, File → New → Other,
  Project → Options, окно ошибок компиляции, окно запущенной программы, консольное окно.
- Замерить размеры, отступы, цвета, шрифты (MS Sans Serif 8 / Tahoma, Courier New 10), порядок значков.
- Делать нашу копию и настоящую программу рядом, снимать оба экрана и править, пока не совпадёт.
- Картинки и логотипы Borland не копируем (игра на публичном сайте) — значки рисуем похожими своими.

## 1. Вид «точь-в-точь»
1. Починить выпадающие меню (сейчас стили игры делают их тёмными круглыми кнопками) — серые плоские меню Windows 2000.
2. Отдельные окна на синем рабочем столе, как в Builder: главная полоса сверху, Object Inspector и Object TreeView слева,
   окно редактора `Unit1.cpp` с ClassExplorer, форма `Form1` с точками. Окна таскаются, сворачиваются, закрываются;
   View → Object Inspector (F11), View → Forms… и т. д. возвращают окна. Начальная раскладка — как на снимке автора.
3. Главная полоса: полное меню (с Database и Window), две строки значков, поле `<None>`, стрелки прокрутки палитры.
4. Редактор: внизу «строка: столбец | Insert», вкладки `Unit1.cpp / Unit1.h / Diagram`; слева ClassExplorer.
5. Убрать наши серые полосы-подсказки. Имена по умолчанию — Project1 / Unit1 / Form1.

## 2. Два режима в комнате «Практика»
- **Пустой Builder (свободный режим).** Как после запуска настоящей программы: пустой Project1 с Form1.
  Можно делать что угодно. Любая лаба открывается «как в оригинале» — File → Open Project (Ctrl+F11):
  окно открытия файла Windows с папками `Тема 01 … Тема 15`, внутри файлы лаб (`Лаба 1 — Вариант 1.bpr`).
- **Лабы по темам (с обучалкой).** Список строго по темам 1–15: папка темы → все её лабы → задания.
  Показывать «решено X из N» у темы и у лабы.

## 3. Обучение с нуля, как в настоящей программе
1. Каждая лаба начинается с пустого Builder. Студент делает всё сам:
   File → New → Application (оконная) или Console Wizard (консольная) → кладёт компоненты с палитры →
   меняет свойства в Object Inspector → двойной щелчок = обработчик (Builder сам пишет `void __fastcall TForm1::Button1Click…`) →
   пишет код → F9.
2. Обучалка по шагам в окошке задания: каждый шаг проверяется сам (✓ форма создана, ✓ на форме Button1, ✓ Caption = «Нажми»,
   ✓ обработчик есть, ✓ программа работает). Ошибся — подсказка, что не так.
3. Картинка «как должно выглядеть»: форма-эталон нарисована по `vcl.ref` из labs.json — видно, где кнопка, где Edit, какие надписи.
4. Порядок: обучалки «первая консольная программа» и «первая форма» → лабы по темам; подсказки постепенно убираются.

## 4. Проверка на настоящей программе
- Пройти в настоящем Builder 6 несколько заданий (консольное, одна форма, две формы, ошибка компиляции) — записать,
  что он сам пишет в Unit1.cpp / Unit1.h / Project1.cpp, какие сообщения (например `E2451 Undefined symbol 'Form2'`).
- Повторить то же в игре и исправить отличия.
