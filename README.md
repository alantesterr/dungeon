# Подземелье знаний

Игра для подготовки к РК и экзаменам: C++, Архитектура ЭВМ, Философия, ИКТ.
Сайт: https://alantesterr.github.io/dungeon/

Всё работает без сервера: открой `index.html` через любой статический хостинг.
Данные — в `data/` (конспект C++ `cpp15.json`, темы предметов `data/subjects/`).
Прогресс хранится в браузере (`localStorage`, ключ `sp-dungeon-v1`).
Графика и авторы — `assets/CREDITS.txt`.

## Для автора

### Подземелье: вопросы по темам силлабуса (Архитектура ЭВМ, Философия)

- Философия — `data/subjects/phil/`: тот же формат (topics.json + tNN.txt + lNN.txt), в topics.json
  есть `units` — разделы на карте тем. 500 тестов разложены по темам скриптом; дословные
  повторы в игре показываются один раз.

- Папка `data/subjects/arch/`: `topics.json` — 15 тем силлабуса (`n`, `rk`, `title`, `file`),
  `t01.txt` … `t08.txt` — вопросы темы в формате Тестера (`<question>`, `<variant>`,
  `<variantright>`, `<variant_keyboard>`, `<explain>`).
- **Добавить тему** (после лекции или лабы): положить `tNN.txt` и вписать имя файла
  в поле `file` темы в `topics.json` — тема перестанет быть «скоро».
- **Добавить вопросы** в тему — просто дописать их в её `tNN.txt`. Комнаты собираются
  сами (по 10 вопросов подряд) + босс темы.
- Лекции у алтаря — `lNN.txt` (поле `lecture`). Лабораторные EWB — отдельный уровень:
  тема `n: 16`, `lab: true`, файлы `tewb.txt` и `lewb.txt` (номер 16 — только ключ,
  в игре уровень подписан «Лабы: EWB»).
- Прогресс хранится по тексту вопроса: если поменять формулировку, вопрос станет «новым».
- Игра: `js/data.js` (загрузка предметов, `D.parseTxt`, сохранение v2 с переносом v1),
  `js/game.js` (бой: ошибка не снимает HP монстра, вопрос возвращается через 3–5
  вопросов; страж без урона; окна «Объясни» и «Google»). После правок — поднять `?v=`
  в `index.html`.

### Подземелье: ИКТ — предмет «только тесты»

- Папка `data/subjects/ict/`: `levels.json` (уровни и их файлы), `rk1.txt`, `rk2.txt`, `exam.txt`
  в формате Тестера (поддерживается `<question_image>data:image/…</question_image>`).
- Уровень = набор файлов: РК2 = `rk1.txt` + `rk2.txt`, Экзамен = все. Один и тот же вопрос
  в разных файлах — один id (текст без знаков препинания + верный ответ), прогресс общий.
- Выбор вопросов — `D.drillWeight` в `js/data.js`: новый 5, ошибка 10 (пока «остывает» — 1.2),
  верно подряд 1 / 2 / 3+ раз — 2 / 0.6 / 0.15. Тренировка — 10 вопросов (`D.drillPick`).
