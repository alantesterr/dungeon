<question> If you declare a variable (e.g., int MyCounter;) in the protected section of the form class, who can access it?
<tr>Если объявить переменную (например, int MyCounter;) в секции protected класса формы, кто может к ней обращаться?</tr>
<variantright> The form class itself and any classes derived from it <tr>Сам класс формы и все классы, производные от него</tr>
<variant> Only the form class itself <tr>Только сам класс формы</tr>
<variant> Any code in the entire application <tr>Любой код во всём приложении</tr>
<variant> Only the VCL/FMX framework <tr>Только библиотека VCL/FMX</tr>
<variant> Only components declared in the same file <tr>Только компоненты, объявленные в этом же файле</tr>
<explain>Почему верно: protected — «семейный доступ»: видят сам класс формы и все классы, производные от него.
Ловушки: «только сам класс» — это private; «любой код» — это public; VCL и «компоненты в том же файле» — неверно.
По лекции: тема 12, раздел «Как наследование влияет на public, protected и private?».
Источник: база преподавателя (question_c++_OOP_2025) ⭐</explain>
