<question> (УМКД) What is inheritance?

<variant> hiding the fields of a class <tr>скрытие полей класса</tr>

<question> (УМКД) What is the main advantage of inheritance?
<tr>(УМКД) Главное преимущество наследования?</tr>
<variantright> reuse of existing code without changing the base class <tr>повторное использование готового кода без изменения базового класса</tr>
<variant> the program runs without a compiler <tr>программа работает без компилятора</tr>
<variant> all fields become public <tr>все поля становятся public</tr>
<variant> objects take no memory <tr>объекты не занимают памяти</tr>
<explain>Вопрос по УМКД (добавлен к базе).

<question> (УМКД) With public inheritance, how are private members of the base class accessible in the derived class?
<tr>(УМКД) Как при public-наследовании доступны private-члены базового класса в наследнике?</tr>
<variantright> they are not accessible directly (only through base class methods) <tr>напрямую недоступны (только через методы базового класса)</tr>
<variant> they become public <tr>становятся public</tr>
<variant> they become protected <tr>становятся protected</tr>

<explain>Вопрос по УМКД (добавлен к базе).

По лекции: тема 12, раздел «2. Доступ при наследовании» — таблица.</explain>

<question> (УМКД) What is method overriding?
<tr>(УМКД) Что такое переопределение метода?</tr>
<variantright> a method in the derived class with the same name and parameters as in the base class <tr>метод в наследнике с тем же именем и параметрами, что в базовом</tr>
<variant> two methods with the same name but different parameters in one class <tr>два метода с одним именем, но разными параметрами в одном классе</tr>
<variant> deleting a method of the base class <tr>удаление метода базового класса</tr>
<variant> calling a method twice <tr>вызов метода дважды</tr>
<explain>Вопрос по УМКД (добавлен к базе).

<question> (УМКД) What is a virtual method?

По лекции: тема 12, раздел «3. Переопределение и виртуальные функции».</explain>
