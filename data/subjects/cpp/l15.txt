## 🐣 С нуля — для тех, кто не знает ООП
**Компонент — готовая «деталь» для формы** (класс-наследник `TComponent`), которую берут с палитры. Главные для тестов — Edit, Label, Memo, Button.
**Где текст:** Edit (одна строка ввода) — `Text`; Label и Button — `Caption`; Memo (много строк) — `Lines`, это список строк.
```
Label1->Caption = Edit1->Text;          // скопировать из поля в надпись
Edit1->Text = "";                         // очистить поле
Memo1->Lines->Add("новая строка");        // добавить строку в конец Memo
Memo1->Lines->Insert(0, "первая");        // вставить в начало
Memo1->Lines->Strings[0];                 // первая строка (счёт с 0!)
Memo1->Lines->Count;                      // сколько строк
Memo1->Lines->Delete(Memo1->Lines->Count - 1);   // удалить последнюю
Memo1->Lines->Clear();                    // очистить всё
```
**Выделение и буфер обмена:** `SelStart` — откуда выделено, `SelLength` — сколько; `SelectAll()` — выделить всё; `CopyToClipboard()` = Ctrl+C, `CutToClipboard()` = Ctrl+X.
**Свой компонент.** Можно сделать свою деталь: взять похожую (например, TEdit), унаследоваться и добавить своё (свойства через `__property`, события). Потом зарегистрировать функцией `Register()` — и она появится на палитре рядом со стандартными.

! Дополнение: компонент
**Компонент** — самостоятельный «строительный блок» (self-contained building block), который кладут на форму: класс-наследник **TComponent** с published-свойствами и событиями, которые видны в Object Inspector.
- **Класс** — описание (тип). **Объект** — экземпляр класса в памяти. **Компонент** — класс особого вида (наследник TComponent), который зарегистрирован в IDE, лежит на палитре и настраивается мышью при проектировании.
- **Стандартные** компоненты — из VCL (Button, Edit…). **Пользовательские** — созданные программистом, обычно наследованием от стандартных.
- **Зачем свои:** один раз сделать элемент с нужным поведением (поле только для чисел, метка-счётчик, кнопка с подсветкой) и использовать во многих формах и проектах.
- **Роль наследования:** новый компонент наследует всё от базового и добавляет своё. **Выбор базового:** берут самый близкий по поведению: на основе TLabel (надпись), TEdit (поле ввода), TButton (кнопка); TGraphicControl — свой рисованный элемент без окна; TWinControl/TCustomControl — с окном и фокусом; TComponent — невизуальный.
! Дополнение: этапы создания (C++Builder 6)
1. **Component → New Component**: Ancestor type — базовый класс (например TLabel), Class Name — TMyLabel, Palette Page — вкладка палитры (например Samples). Builder создаёт MyLabel.cpp и MyLabel.h.
2. Описать класс: поля, методы, свойства в секции `__published` (тогда они появятся в Object Inspector), события — свойства типа TNotifyEvent.
3. Функция `Register()` вызывает `RegisterComponents("Samples", classes, 0)` — так компонент регистрируется.
4. **Component → Install Component** → в пакет (dclusr.bpk) → Compile → компонент появляется на **палитре**.
5. Положить на форму, настроить свойства, проверить в программе; при ошибке — исправить, пересобрать пакет.
```
// MyLabel.h
class PACKAGE TMyLabel : public TLabel          // наследуем стандартную надпись
{
private:
  AnsiString FText;                             // поле для свойства
  int FClicks;
  TNotifyEvent FOnTextChanged;                  // поле события
  void __fastcall SetText(AnsiString v);
protected:
  DYNAMIC void __fastcall Click();              // переопределяем реакцию на щелчок
public:
  __fastcall TMyLabel(TComponent* Owner);
  void __fastcall Reset();                      // свой метод
__published:                                    // видно в Object Inspector
  __property AnsiString Text = {read = FText, write = SetText};
  __property int Clicks = {read = FClicks};
  __property TNotifyEvent OnTextChanged = {read = FOnTextChanged, write = FOnTextChanged};
};

// MyLabel.cpp
__fastcall TMyLabel::TMyLabel(TComponent* Owner) : TLabel(Owner)
{ FText = "Text"; FClicks = 0; Caption = FText; }

void __fastcall TMyLabel::SetText(AnsiString v)
{
  FText = v;
  Caption = FText + " (" + IntToStr(FClicks) + ")";
  if (FOnTextChanged) FOnTextChanged(this);     // вызвать событие, если к нему привязан обработчик
}
void __fastcall TMyLabel::Click() { FClicks++; SetText(FText); TLabel::Click(); }
void __fastcall TMyLabel::Reset() { FClicks = 0; SetText(FText); }

namespace Mylabel
{
  void __fastcall PACKAGE Register()
  {
    TComponentClass classes[1] = {__classid(TMyLabel)};
    RegisterComponents("Samples", classes, 0);
  }
}
```
**Свойства** компонента — __property с read/write (тема 14). **Методы** — обычные функции класса. **События компонента** — свойства-указатели на обработчики (TNotifyEvent); компонент «вызывает» событие, когда что-то произошло, а обработчик пишет пользователь компонента. Повторное использование: установленный компонент доступен в любом проекте с палитры.
! Дополнение: текст между компонентами (для теста)
| Задача | Код |
| Edit → Label | `Label1->Caption = Edit1->Text;` |
| переместить (вырезать) из Edit | `Button1->Caption = Edit1->Text; Edit1->Text = "";` |
| добавить строку в конец Memo | `Memo1->Lines->Add(Edit1->Text);` |
| склеить и добавить | `Memo1->Lines->Add(Label1->Caption + Edit1->Text);` |
| вставить строку в начало | `Memo1->Lines->Insert(0, "Первая");` |
| первая строка Memo → Edit | `Edit1->Text = Memo1->Lines->Strings[0];` (нумерация с 0: третья строка — Strings[2]) |
| количество строк | `Memo1->Lines->Count` |
| удалить последнюю строку | `Memo1->Lines->Delete(Memo1->Lines->Count - 1);` |
| очистить Memo | `Memo1->Lines->Clear();` |
| скопировать Memo в Memo | `Memo2->Lines->Assign(Memo1->Lines);` |
| весь текст Memo одной строкой | `Edit1->Text = Memo1->Lines->Text;` (в Edit видна только одна строка) |
**Выделение и буфер обмена (Clipboard)** — у Edit и Memo:
- `SelectAll()` — выделить всё; `SelStart` — с какого символа выделение; `SelLength` — длина выделения; `SelText` — сам выделенный текст. Выделить первые 5 символов: `Edit1->SelStart = 0; Edit1->SelLength = 5;`
- `CopyToClipboard()` — копировать, `CutToClipboard()` — вырезать, `PasteFromClipboard()` — вставить. Перед вырезанием проверь, что что-то выделено: `if (Edit1->SelLength > 0)`.
- Весь Memo в буфер: `Memo1->SelectAll(); Memo1->CopyToClipboard();`
- `ReadOnly = true` у Memo — пользователь не печатает, но из кода текст менять можно.

## Конспект по вопросам УМКД
Коротко по каждому вопросу УМКД — на эти разделы ссылаются тесты.

## Что такое компонент в C++Builder?
**Ответ из УМКД:** Самостоятельный строительный блок приложения — класс-наследник TComponent, который размещается на форме и настраивается в Object Inspector.
Компонент — самостоятельный «строительный блок» приложения: класс-наследник `TComponent`, который кладут на форму и настраивают в Object Inspector.

## Разница между классом, объектом и компонентом?
**Ответ из УМКД:** Класс — описание типа; объект — экземпляр класса в памяти; компонент — особый класс (наследник TComponent), зарегистрированный в IDE и размещаемый на палитре и форме.
Класс — описание типа; объект — экземпляр в памяти; компонент — особый класс VCL, зарегистрированный в IDE, который есть на палитре.

## Что такое пользовательский компонент?
**Ответ из УМКД:** Компонент, созданный программистом (обычно наследованием от стандартного VCL-компонента) и установленный на палитру.
Пользовательский компонент — свой компонент, обычно наследник стандартного (TEdit → TNumEdit), установленный на палитру.

## Зачем создают свои компоненты?
**Ответ из УМКД:** Чтобы один раз реализовать нужное поведение и повторно использовать его в разных формах и проектах.
Свой компонент пишут один раз и потом ставят на любые формы и проекты.

## Роль наследования при создании компонента?
**Ответ из УМКД:** Новый компонент наследует свойства, методы и события базового и добавляет свои — не нужно писать всё заново.
Наследник получает все свойства, методы и события базового компонента и добавляет свои.

## Как выбирается базовый компонент?
**Ответ из УМКД:** Берут ближайший по поведению: TLabel, TEdit, TButton для доработки стандартных; TGraphicControl или TCustomControl для своих рисуемых; TComponent для невизуальных.
Базовый выбирают по поведению: TLabel, TEdit, TButton — доработать стандартный; TGraphicControl / TCustomControl — свой рисуемый; TComponent — невизуальный.

## Какие свойства можно добавить в компонент?
**Ответ из УМКД:** Любые данные с доступом через __property (read/write); в секции __published они видны в Object Inspector.
Свойства добавляют через `__property` (read/write); в секции `__published` они видны в Object Inspector.

## Как добавить методы в компонент?
**Ответ из УМКД:** Объявить функции-члены в классе компонента и описать их; можно переопределять виртуальные методы базового (Click, Paint).
Методы — функции-члены класса компонента; можно переопределять виртуальные методы базового (Click, Paint).

## Что такое события компонента?
**Ответ из УМКД:** Свойства-указатели на обработчики (TNotifyEvent и др.), которые компонент вызывает при определённых действиях; обработчик пишет пользователь компонента.
События — свойства-указатели на обработчики (`TNotifyEvent`); компонент вызывает их при действиях, а код обработчика пишет пользователь компонента.

## Как регистрируется компонент в C++Builder?
**Ответ из УМКД:** Функцией Register() с вызовом RegisterComponents("Страница", классы, n) в модуле компонента.
Регистрация — функция `Register()` с `RegisterComponents("Страница", классы, n)`.

## Как добавить компонент на палитру?
**Ответ из УМКД:** Component → Install Component → выбрать пакет → Compile/Install; компонент появится на указанной странице палитры.
На палитру: Component → Install Component → пакет → Compile/Install.

## Основные этапы создания и проверки компонента?
**Ответ из УМКД:** Выбор базового класса → New Component → свойства, методы, события → Register → установка в пакет → размещение на форме → тестирование и отладка.
Этапы: базовый класс → New Component → свойства, методы, события → Register → установка в пакет → на форму → тест.

## Доп.: Edit, Label, Button — Text и Caption
Где у компонента текст: у **TEdit** (поле ввода) — `Text`; у **TLabel** и **TButton** (только показывают) — `Caption`.
```
Label1->Caption = Edit1->Text;            // скопировать
Button1->Caption = Edit1->Text; Edit1->Text = "";   // переместить = скопировать + очистить
Button1->Caption = "";                    // надпись исчезнет, кнопка останется
```
TEdit однострочный: многострочный текст в нём покажется только до первого переноса. `ReadOnly = true` запрещает ручной ввод (из кода менять Text можно).

## Доп.: Memo и его строки Lines
У **TMemo** строки лежат в `Lines` (список TStrings), нумерация с 0:
| Нужно | Код |
| добавить строку в конец | `Memo1->Lines->Add("текст")` |
| вставить в начало | `Memo1->Lines->Insert(0, "текст")` |
| строка №1 (первая) | `Memo1->Lines->Strings[0]` |
| третья строка | `Strings[2]` |
| сколько строк | `Memo1->Lines->Count` |
| удалить последнюю | `Lines->Delete(Lines->Count - 1)` |
| очистить | `Memo1->Lines->Clear()` |
| скопировать весь Memo в другой | `MemoDest->Lines->Assign(MemoSource->Lines)` |
| весь текст одной строкой | `Memo1->Lines->Text` |
Склеить строки — плюсом: `Memo1->Lines->Add(Label1->Caption + Edit1->Text)`.

## Доп.: выделение текста и буфер обмена
`SelStart` — откуда начинается выделение, `SelLength` — его длина (если > 0 — что-то выделено), `SelectAll()` — выделить всё.
Буфер обмена: `CopyToClipboard()` (Ctrl+C), `CutToClipboard()` (Ctrl+X), `PasteFromClipboard()` (Ctrl+V). Скопировать весь Memo: `SelectAll()`, потом `CopyToClipboard()`.

Положить на форму, настроить свойства, проверить в программе; при ошибке — исправить, пересобрать пакет.
```
// MyLabel.h
class PACKAGE TMyLabel : public TLabel          // наследуем стандартную надпись
{
private:
  AnsiString FText;                             // поле для свойства
  int FClicks;
  TNotifyEvent FOnTextChanged;                  // поле события
  void __fastcall SetText(AnsiString v);
protected:
  DYNAMIC void __fastcall Click();              // переопределяем реакцию на щелчок
public:
  __fastcall TMyLabel(TComponent* Owner);
  void __fastcall Reset();                      // свой метод
__published:                                    // видно в Object Inspector
  __property AnsiString Text = {read = FText, write = SetText};
  __property int Clicks = {read = FClicks};
  __property TNotifyEvent OnTextChanged = {read = FOnTextChanged, write = FOnTextChanged};
};
// MyLabel.cpp
__fastcall TMyLabel::TMyLabel(TComponent* Owner) : TLabel(Owner)
{ FText = "Text"; FClicks = 0; Caption = FText; }
void __fastcall TMyLabel::SetText(AnsiString v)
{
  FText = v;
  Caption = FText + " (" + IntToStr(FClicks) + ")";
  if (FOnTextChanged) FOnTextChanged(this);     // вызвать событие, если к нему привязан обработчик
}
void __fastcall TMyLabel::Click() { FClicks++; SetText(FText); TLabel::Click(); }
void __fastcall TMyLabel::Reset() { FClicks = 0; SetText(FText); }
namespace Mylabel
{
  void __fastcall PACKAGE Register()
  {
    TComponentClass classes[1] = {__classid(TMyLabel)};
    RegisterComponents("Samples", classes, 0);
  }
}
```
Свойства компонента — __property с read/write (тема 14). Методы — обычные функции класса. События компонента — свойства-указатели на обработчики (TNotifyEvent); компонент «вызывает» событие, когда что-то произошло, а обработчик пишет пользователь компонента. Повторное использование: установленный компонент доступен в любом проекте с палитры.

! Вопрос УМКД: **Какие свойства можно добавить в компонент?** — Любые данные с доступом через __property (read/write); в секции __published они видны в Object Inspector.
! Вопрос УМКД: **Как добавить методы в компонент?** — Объявить функции-члены в классе компонента и описать их; можно переопределять виртуальные методы базового (Click, Paint).
! Вопрос УМКД: **Что такое события компонента?** — Свойства-указатели на обработчики (TNotifyEvent и др.), которые компонент вызывает при определённых действиях; обработчик пишет пользователь компонента.
! Вопрос УМКД: **Как регистрируется компонент в C++Builder?** — Функцией Register() с вызовом RegisterComponents("Страница", классы, n) в модуле компонента.
! Вопрос УМКД: **Как добавить компонент на палитру?** — Component → Install Component → выбрать пакет → Compile/Install; компонент появится на указанной странице палитры.
! Вопрос УМКД: **Основные этапы создания и проверки компонента?** — Выбор базового класса → New Component → свойства, методы, события → Register → установка в пакет → размещение на форме → тестирование и отладка.

## Текст между компонентами (для теста)
| Задача | Код |
| Edit → Label | Label1->Caption = Edit1->Text; |
| переместить (вырезать) из Edit | Button1->Caption = Edit1->Text; Edit1->Text = ""; |
| добавить строку в конец Memo | Memo1->Lines->Add(Edit1->Text); |
| склеить и добавить | Memo1->Lines->Add(Label1->Caption + Edit1->Text); |
| вставить строку в начало | Memo1->Lines->Insert(0, "Первая"); |
| первая строка Memo → Edit | Edit1->Text = Memo1->Lines->Strings[0]; (нумерация с 0: третья строка — Strings[2]) |
| количество строк | Memo1->Lines->Count |
| удалить последнюю строку | Memo1->Lines->Delete(Memo1->Lines->Count - 1); |
| очистить Memo | Memo1->Lines->Clear(); |
| скопировать Memo в Memo | Memo2->Lines->Assign(Memo1->Lines); |
| весь текст Memo одной строкой | Edit1->Text = Memo1->Lines->Text; (в Edit видна только одна строка) |

Выделение и буфер обмена (Clipboard) — у Edit и Memo:

SelectAll() — выделить всё; SelStart — с какого символа выделение; SelLength — длина выделения; SelText — сам выделенный текст. Выделить первые 5 символов: Edit1->SelStart = 0; Edit1->SelLength = 5;
CopyToClipboard() — копировать, CutToClipboard() — вырезать, PasteFromClipboard() — вставить. Перед вырезанием проверь, что что-то выделено: if (Edit1->SelLength > 0).
ReadOnly = true у Memo — пользователь не печатает, но из кода текст менять можно.
! Как в тесте: Весь Memo в буфер: Memo1->SelectAll(); Memo1->CopyToClipboard();
