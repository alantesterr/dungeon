## 🐣 С нуля — для тех, кто не знает ООП
**C++Builder — это не язык, а программа-мастерская (IDE).** В ней всё сразу: где писать код, где рисовать окно, кнопка «запустить», поиск ошибок. Язык внутри — обычный C++.
**Как выглядит экран:**
- **Форма** — окно твоей будущей программы, в точечку. На неё кладут кнопки и поля.
- **Палитра компонентов** (сверху, вкладки Standard, Additional…) — «ящик с деталями»: Button (кнопка), Edit (поле ввода), Label (надпись), Timer (таймер).
- **Object Inspector** (слева) — «паспорт» выделенной детали. Вкладка **Properties** — свойства (Caption — надпись, Color — цвет, Width — ширина), вкладка **Events** — события (OnClick — что делать при нажатии).
- **Code Editor** — где пишешь код (файл Unit1.cpp).
**Первая программа за минуту:** положи на форму Button и Label → двойной щелчок по кнопке → IDE сама создаст функцию → впиши `Label1->Caption = "Привет!";` → F9 (запуск) → нажми кнопку.
**Видимые и невидимые детали.** Кнопку видно и на форме, и в работающей программе — это **визуальный** компонент (элемент управления). Таймер виден только значком при проектировании, в программе его не видно — **невизуальный**.
**Проект** — папка файлов одной программы: `.bpr` (сам проект), `Unit1.cpp` (код), `Unit1.h` (описание формы), `Unit1.dfm` (как выглядит форма). Из них собирается `.exe`.

! Дополнение: что такое IDE и C++Builder

! Дополнение: проект, компиляция, запуск
- **Проект** — набор файлов программы: Project1.bpr (проект), Project1.cpp (главный файл с WinMain), Unit1.cpp (код формы), Unit1.h (объявление класса формы), Unit1.dfm (вид формы), Project1.res (ресурсы, значок).
- Создать: **File → New → Application** (оконное) или **File → New → Other → Console Wizard** (консольное). Сохранить всё: **File → Save All** (Shift+Ctrl+S); открыть: File → Open Project.
- **Этапы:** препроцессор (#include) → компиляция каждого .cpp в .obj → компоновка (линковка) с библиотеками → Project1.exe → запуск. **F9** делает всё сразу; Ctrl+F9 — только собрать (Make).
- **Release-сборка** (из ООП-лабы 1-2): чтобы exe работал на компьютере без Builder, в Project → Options снять «Build with runtime packages» (Packages) и «Use dynamic RTL» (Linker).
! Дополнение: ошибки и отладка
- **Синтаксическая** — нарушены правила языка (нет ;, опечатка в слове, лишняя скобка). Находит компилятор, программа не собирается.
- **Семантическая** — запись правильная, но смысл недопустим: необъявленная переменная, несовместимые типы, вызов функции с неверными аргументами. Тоже находит компилятор.
- **Логическая** — программа собирается и работает, но результат неверный (не та формула, 1/3 вместо 1/3.). Компилятор не находит — ищут тестированием и отладкой.
- **Отладка (debugging)** — поиск и исправление ошибок: точка останова (щелчок на поле слева от строки или F5), пошаговое выполнение F8 (Step Over) и F7 (Trace Into), просмотр переменных (Ctrl+F7 Evaluate/Modify, Watch), Run to Cursor (F4).

**Компоненты из лабы с часами:**
- **StaticText**: `Alignment` — выравнивание текста; `BorderStyle = sbsSunken` — вдавленная рамка (sbsNone — без рамки, sbsSingle — линия); `AutoSize = true` — размер подгоняется под текст.

- Текущее время: `Now().TimeString()`, дата — `Date().DateString()`.
- `FormStyle = fsStayOnTop` — форма всегда поверх других окон.

## Что такое Object Inspector?
**Ответ из УМКД:** Окно IDE для просмотра и изменения свойств (Properties) и событий (Events) выбранного объекта.
Object Inspector — окно слева: вкладка **Properties** (свойства выделенного объекта) и **Events** (события). ## Что такое палитра компонентов (Component Palette)?
**Ответ из УМКД:** Панель с вкладками готовых компонентов (Standard, Additional, Win32, System, Dialogs…), которые кладут на форму.
Палитра компонентов — вкладки Standard, Additional, Win32, System, Dialogs… Компоненты — «строительные блоки», которые кладут на форму. **Визуальные** (элементы управления, controls: Button, Edit, Label) видны и в дизайнере, и при работе; **невизуальные** (Timer, диалоги) при работе не видны.
Часы: Timer с Interval = 1000 и в OnTimer — `Label1->Caption = Now().TimeString();`

## Что такое дизайнер форм (Form Designer)?
**Ответ из УМКД:** Окно, где визуально строят интерфейс: размещают, двигают и меняют размеры компонентов на форме.
Дизайнер форм — окно с точечной сеткой, где мышкой размещают, двигают и растягивают компоненты.

Проект — набор файлов одной программы: `Project1.bpr` (файл проекта, Borland Project), `Project1.cpp` (с WinMain), `Unit1.cpp` (код), `Unit1.h` (класс формы), `Unit1.dfm` (вид формы), `.res` (иконка). Из них собирается `.exe`.

**Ответ из УМКД:** Сохранение → препроцессор → компиляция .cpp в .obj → компоновка с библиотеками в .exe → запуск (F9).
Сохранить → препроцессор → компиляция .cpp в .obj → компоновка с библиотеками в .exe → запуск (F9).

## Что такое отладка?
**Ответ из УМКД:** Поиск и исправление ошибок с помощью точек останова, пошагового выполнения (F7, F8) и просмотра значений переменных.
Отладка — поиск ошибок: точки останова (F5), пошагово (F7 — с заходом в функции, F8 — без), просмотр значений переменных.

## Разница между синтаксической, семантической и логической ошибкой?
**Ответ из УМКД:** Синтаксическая — нарушение правил записи (компилятор не соберёт); семантическая — недопустимый смысл, например необъявленная переменная или несовместимые типы (тоже ловит компилятор); логическая — программа работает, но неверно (ищется тестированием и отладкой).
**Синтаксическая** — нарушены правила записи (нет `;`), компилятор не соберёт. **Семантическая** — недопустимый смысл (необъявленная переменная, несовместимые типы), тоже ловит компилятор. **Логическая** — программа работает, но неправильно; ищется тестированием.

Release-сборка (из ООП-лабы 1-2): чтобы exe работал на компьютере без Builder, в Project → Options снять «Build with runtime packages» (Packages) и «Use dynamic RTL» (Linker).

! Вопрос УМКД: **Что такое проект в C++Builder?** — Набор файлов одной программы: .bpr, Project1.cpp, Unit1.cpp, Unit1.h, Unit1.dfm, .res; из него собирается exe.
! Вопрос УМКД: **Основные этапы компиляции и запуска?** — Сохранение → препроцессор → компиляция .cpp в .obj → компоновка с библиотеками в .exe → запуск (F9).

## Ошибки и отладка
Синтаксическая — нарушены правила языка (нет ;, опечатка в слове, лишняя скобка). Находит компилятор, программа не собирается.
Семантическая — запись правильная, но смысл недопустим: необъявленная переменная, несовместимые типы, вызов функции с неверными аргументами. Тоже находит компилятор.
Логическая — программа собирается и работает, но результат неверный (не та формула, 1/3 вместо 1/3.). Компилятор не находит — ищут тестированием и отладкой.
Отладка (debugging) — поиск и исправление ошибок: точка останова (щелчок на поле слева от строки или F5), пошаговое выполнение F8 (Step Over) и F7 (Trace Into), просмотр переменных (Ctrl+F7 Evaluate/Modify, Watch), Run to Cursor (F4).

! Вопрос УМКД: **Что такое отладка?** — Поиск и исправление ошибок с помощью точек останова, пошагового выполнения (F7, F8) и просмотра значений переменных.
! Вопрос УМКД: **Разница между синтаксической, семантической и логической ошибкой?** — Синтаксическая — нарушение правил записи (компилятор не соберёт); семантическая — недопустимый смысл, например необъявленная переменная или несовместимые типы (тоже ловит компилятор); логическая — программа работает, но неверно (ищется тестированием и отладкой).

## Формулировки из теста (англ. — с переводом)
| Термин | Что это |
| Borland C++ Builder 6 | Integrated Development Environment, IDE (интегрированная среда разработки): редактор, дизайнер форм, компилятор и отладчик вместе. |
| Object Inspector (инспектор объектов) | Здесь смотрят и меняют properties and events (свойства и события) выделенного объекта. Свойства компонента задают именно здесь. |
| Code Editor (редактор кода) | Хранит набор команд программы (текст Unit1.cpp). |
| Component Palette (палитра компонентов) | Вкладки Standard, Additional, System… с компонентами. |
| Components (компоненты) | Self-contained building blocks (самостоятельные «кирпичики»), которые кладут на форму. |
| Visual components = Controls (визуальные компоненты = элементы управления) | Выглядят одинаково при проектировании и во время работы: Button, Edit, Label. |
| Non-visual components (невизуальные) | Не видны во время работы: Timer, MainMenu, OpenDialog. У них нет Width и Height. |
| .bpr | Файл проекта в Builder 6 (Project1.bpr). Unit1.cpp — код, Unit1.h — объявление класса формы, Unit1.dfm — вид формы. |

Компоненты из лабы с часами:

StaticText: Alignment — выравнивание текста; BorderStyle = sbsSunken — вдавленная рамка (sbsNone — без рамки, sbsSingle — линия); AutoSize = true — размер подгоняется под текст.
BitBtn (кнопка с картинкой, вкладка Additional): Kind — готовый вид кнопки (bkOK, bkCancel, bkClose…); Glyph — картинка на кнопке.
Текущее время: Now().TimeString(), дата — Date().DateString().
FormStyle = fsStayOnTop — форма всегда поверх других окон.
