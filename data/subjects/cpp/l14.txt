## Свойство, get и set

Свойство — характеристика объекта (переменная некоторого типа), описывающая его внутреннее состояние: возраст, цвет, ширина. Хорошая практика — хранить её в закрытом поле, а читать и менять через методы.

```
class Person
{
private:
  int age;                                  // данные спрятаны
public:
  int getAge() const { return age; }        // getter — чтение
  void setAge(int a)                        // setter — изменение с проверкой
  {
    if (a >= 0 && a <= 150) age = a;
    else cout << "Неверный возраст" << endl;
  }
};
```
Зачем инкапсулировать: нельзя записать неверное значение (возраст −5), можно менять внутреннее устройство класса, не трогая код, который его использует.
Getter возвращает значение поля; setter принимает новое и проверяет его.
Свойство «только для чтения» — есть getter, нет setter.
Public-поле можно изменить как угодно; инкапсулированное свойство — только через проверку.
Интерфейс и реализация: объявление класса (что он умеет — в .h) отдельно от определения методов (как — в .cpp).

## Свойства в C++Builder: __property
```
class TPerson
{
private:
  int FAge;                                 // поле (в VCL принято начинать с F)
  void SetAge(int v) { if (v >= 0) FAge = v; }
public:
  __property int Age = { read = FAge, write = SetAge };
};
TPerson p;
p.Age = 20;        // на самом деле вызывается SetAge(20)
cout << p.Age;     // читается FAge
```
Снаружи свойство выглядит как обычное поле, а внутри read и write указывают поле или метод. Без write — свойство только для чтения. Если свойство объявить в секции __published у компонента, оно появляется в Object Inspector (тема 15). Все свойства компонентов (Caption, Width, Color…) устроены именно так: Form1->Width = 300; вызывает метод, который перерисовывает форму.

## Для теста на английском

Своё свойство в C++Builder объявляют ключевым словом __property: оно даёт чтение и запись закрытого (private) поля через read/write, например __property int Age = {read = FAge, write = SetAge};

## Вопросы УМКД к теме 14 — с ответами
- **Что такое свойство класса?** — Характеристика (атрибут) объекта, описывающая его состояние; хранится в поле и обычно читается/изменяется через методы доступа.
- **Почему данные класса обычно инкапсулируют?** — Чтобы защитить их от неверных значений и случайных изменений и иметь возможность менять реализацию без изменения внешнего кода.
- **Что такое getter и setter?** — Методы доступа: getter возвращает значение поля, setter записывает новое значение (с проверкой).
- **Назначение getter?** — Дать возможность прочитать значение закрытого поля.
- **Назначение setter?** — Дать возможность изменить закрытое поле контролируемо — с проверкой допустимости значения.
- **Как setter проверяет данные?** — Сравнивает новое значение с допустимым диапазоном и записывает его только если оно верное, иначе сообщает об ошибке.
- **Разница между public-полем и инкапсулированным свойством?** — Public-поле можно изменить любым значением напрямую; инкапсулированное — только через методы, которые проверяют значение.
- **Как реализуются свойства в пользовательском классе?** — Private-поле + public get/set методы; в C++Builder — __property тип Имя = {read = …, write = …};
- **Как обращаться к свойствам извне класса?** — Через вызов методов obj.getAge(), obj.setAge(20) или, для __property, как к полю: obj.Age = 20.
- **Преимущества свойств и инкапсуляции?** — Корректность данных, защита, скрытие реализации, простота изменения класса, возможность свойств только для чтения.
