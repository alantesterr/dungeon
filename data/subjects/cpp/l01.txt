## 1. Программирование и парадигмы
**Программирование**

Программирование — это составление программы: точной инструкции для компьютера на языке, который он может выполнить. Программа = алгоритм, записанный на языке программирования.

Парадигма программирования — общий подход, «стиль мышления», в котором пишут программу:

Процедурная (структурная) — программа это последовательность действий и вызовов функций. Так пишут на C, Pascal, на C++ в темах 1–6.
Объектно-ориентированная (ООП) — программа строится из объектов: данные и действия над ними объединены в классы. C++, Java, C#, Delphi. Это темы 7–15.
Функциональная — программа как набор математических функций без изменения переменных (Haskell, Lisp).
Логическая — описываются факты и правила, а решение ищет сама система (Prolog).

C++ — мультипарадигменный язык: на нём можно писать и процедурно, и объектно-ориентированно.

## 2. Классификация языков программирования
**Уровни языков**
| Уровень | Что это | Примеры |
| Машинный код | команды процессора в двоичном виде, 0 и 1 | 10110000 01100001 |
| Низкого уровня | мнемоники команд процессора, привязаны к конкретному процессору | ассемблер: MOV AL, 61h |

Компилируемые языки (C, C++, Pascal): вся программа заранее переводится компилятором в машинный код — получается .exe. Интерпретируемые (Python, JavaScript): программа выполняется построчно интерпретатором.

## 3. Алгоритм и его свойства
**Алгоритм**

Алгоритм — точное, понятное исполнителю описание конечной последовательности действий, которая приводит от исходных данных к результату.

Свойства алгоритма (их часто спрашивают по одному):

Дискретность — алгоритм разбит на отдельные шаги.
Понятность — каждый шаг понятен исполнителю (компьютер «понимает» только команды своего языка).
Определённость (детерминированность) — каждый шаг однозначен: при одних и тех же данных — один и тот же результат.
Конечность (результативность) — алгоритм заканчивается за конечное число шагов и даёт результат.
Массовость — алгоритм решает не одну задачу, а целый класс задач при разных исходных данных.

Способы задания алгоритма: словесный (обычным языком), псевдокод (полуформальный язык: «ввести x; если x>0 то…»), блок-схема (графически) и программа на языке программирования.

Пример — один алгоритм четырьмя способами. Задача: найти площадь круга по радиусу.

Словесно: «Узнать радиус. Умножить 3,14 на радиус в квадрате. Сообщить результат».
Псевдокод: ввод r; S := 3.14·r²; вывод S.
Программа: cin >> r; S = 3.14*r*r; cout << S;

! Вопрос УМКД: **Что такое алгоритм? Основные свойства? (What is an algorithm?)** — Точное конечное описание последовательности действий, ведущей от исходных данных к результату. Свойства: дискретность, понятность, определённость, конечность (результативность), массовость.
! Вопрос УМКД: **Основные способы задания алгоритма?** — Словесный, псевдокод, блок-схема, программа на языке программирования.

## 4. Блок-схемы и типы алгоритмов
**Блок-схемы**

Блок-схема (flowchart) — графическое изображение алгоритма: блоки соединены стрелками в порядке выполнения. Основные символы (ГОСТ 19.701):

| Фигура | Название | Что означает |
| Овал (скруглённый прямоугольник) | Терминатор | Начало и конец алгоритма |
| Параллелограмм | Данные | Ввод и вывод данных (cin, cout) |
| Прямоугольник | Процесс | Вычисление, присваивание (s = a + b) |
| Ромб | Решение | Проверка условия, два выхода: «да» и «нет» |
| Шестиугольник | Подготовка (модификация) | Заголовок цикла с параметром (for) |
| Прямоугольник с двойными боковыми линиями | Предопределённый процесс | Вызов функции (подпрограммы) |
| Кружок | Соединитель | Переход на другое место схемы |

Три базовых типа алгоритмов (из них строится любой алгоритм):

Линейный (следование, sequence) — действия выполняются строго одно за другим. Лаба 1 — линейные алгоритмы.
Разветвляющийся (ветвление, selection) — есть проверка условия, и дальше выполняется одна из ветвей. В C++ — if, switch (тема 3).
Циклический (повторение, repetition) — группа действий повторяется. В C++ — for, while, do…while (темы 3–4).

! Вопрос УМКД: **Что такое блок-схема, основные символы?** — Графическая запись алгоритма. Овал — начало/конец, параллелограмм — ввод/вывод, прямоугольник — действие, ромб — условие, шестиугольник — цикл с параметром, стрелки — порядок.
! Вопрос УМКД: **Основные типы алгоритмов?** — Линейный (следование), разветвляющийся (ветвление), циклический (повторение).
! Вопрос УМКД: **Разница между последовательным, разветвляющимся и циклическим?** — В линейном все действия выполняются один раз подряд; в разветвляющемся по условию выполняется одна из ветвей; в циклическом группа действий повторяется, пока выполняется условие или заданное число раз.

## 5. Алфавит C++ и лексемы
**Алфавит и лексемы**

Алфавит C++ — символы, из которых можно составлять программу:

прописные и строчные латинские буквы A–Z, a–z и знак подчёркивания _;
арабские цифры 0–9;
специальные символы: + - * / % = < > ! & | ^ ~ ? : ; , . ' " ( ) [ ] { } # \;
пробельные символы: пробел, табуляция, перевод строки.

Русские буквы в алфавит НЕ входят — их можно писать только внутри строк "…" и в комментариях. Имя переменной сумма — ошибка (это вопрос из базы).

Лексема (token) — наименьшая смысловая единица языка, «слово» программы. Компилятор сначала разбивает текст на лексемы. Виды лексем: идентификаторы, ключевые слова, константы (литералы), знаки операций, разделители (; , { } ( )).

Строка sum = a + 15; состоит из 6 лексем: sum, =, a, +, 15, ;. Зачем нужны лексемы: по ним компилятор понимает, где имя, где число, где операция.

! Вопрос УМКД: **Основные элементы синтаксиса C++?** — Алфавит (латинские буквы, цифры, спецсимволы) и лексемы: идентификаторы, ключевые слова, константы, знаки операций, разделители; комментарии.

## 6. Идентификаторы и ключевые слова
**Идентификаторы**

Идентификатор — имя объекта программы: переменной, константы, типа, функции, класса.

Правила:

Состоит из латинских букв, цифр и _.
Начинается с буквы или _, не с цифры.
Большие и маленькие буквы различаются: Sum, sum и SUM — три разных имени.
Не может совпадать с ключевым словом.
Без пробелов и дефисов. В Borland значимы первые 250 символов.
| Правильно | Неправильно | Почему |
| sum, x1, _count, maxValue | 1x | начинается с цифры |
| my_sum | my-sum, my sum | дефис и пробел запрещены |
| Int, Float | int, float | ключевые слова |
| summa | сумма | русских букв нет в алфавите |

Ключевые (зарезервированные) слова — слова из специального набора, которые компилятор понимает по-своему; использовать их как имена нельзя. Главные: int char float double bool void short long unsigned signed const if else switch case default for while do break continue return goto struct class public private protected new delete this true false sizeof enum typedef.

! Вопрос УМКД: **Что такое идентификаторы, ключевые слова, константы и переменные?** — Идентификатор — имя объекта программы. Ключевое слово — зарезервированное слово языка (int, if, return…). Константа — значение, которое не меняется (25, 'A', const double PI). Переменная — именованная область памяти, значение которой можно менять.

## 7. Константы, escape-последовательности, комментарии
**Константы**
| Вид константы | Примеры | Тип |
| Целая десятичная | 25, -7, 0 | int |
| Целая восьмеричная (начинается с 0) | 017 = 15 | int |
| Целая шестнадцатеричная (0x…) | 0x1F = 31 | int |
| Вещественная | 3.14, .5, 2. | double |
| Вещественная в экспоненциальной форме | 1.5e-3 = 1,5·10⁻³, 0.423e-2 | double |
| С суффиксом | 3.5f — float, 100L — long, 10u — unsigned |
| Символьная (в одинарных кавычках) | 'A', '7', '\n' | char |
| Строковая (в двойных кавычках) | "Hello" — в памяти 6 байт: 5 букв и '\0' | массив char |
| Логическая | true, false | bool |

Именованные константы — значение нельзя менять:

```
const double PI = 3.14159;   // константа с типом — так правильнее в C++
#define N 10                 // макрос препроцессора: перед компиляцией N заменится на 10
```
Если написать const int a = 5; a++; — программа не скомпилируется: «Cannot modify a const object» (вопрос из базы).

## Escape-последовательности

Управляющая (escape) последовательность — обратная косая черта \ и символ после неё. Записывает внутри строки или символа то, что нельзя набрать напрямую.

| Запись | Что делает |
| \n | переход на новую строку (new line) |
| \t | горизонтальная табуляция — прыжок к следующей позиции, кратной 8 |
| \a | звуковой сигнал (alert) |
| \b | шаг назад (backspace) |
| \r | возврат каретки в начало строки |
| \f, \v | новая страница, вертикальная табуляция |
| \\ \' \" | сами символы \ ' " |
| \0 | нулевой символ — конец строки |
| \x41, \101 | символ по коду (hex / восьмеричный): тут оба — 'A' |

Комментарии — пояснения для человека, компилятор их пропускает: // до конца строки и /* можно на несколько строк */.

! Вопрос УМКД: **Что такое комментарии и escape-последовательности? Примеры.** — Комментарий — текст для человека, компилятор его пропускает: // …, /* … */. Escape-последовательность — \ + символ для особых знаков: \n новая строка, \t табуляция, \\, \", \0.

## 8. Структура программы в Borland C++
**Структура программы**

Любая программа на C++ состоит из директив препроцессора, объявлений и функций. Выполнение всегда начинается с функции main().

```
#include <iostream.h>   // 1. директивы препроцессора: подключаем библиотеки
#include <conio.h>
#include <math.h>
const double PI = 3.14159; // 2. глобальные объявления (необязательно)
int main()                 // 3. главная функция — с неё начинается выполнение
{                          //    тело функции — в фигурных скобках { }
  double r, s;             // 4. объявление переменных
  cout << "r = ";          // 5. операторы, каждый заканчивается точкой с запятой
  cin >> r;
  s = PI * r * r;
  cout << "S = " << s << endl;
  getch();                 // ждём нажатия клавиши, чтобы окно не закрылось
  return 0;                // 6. возвращаем 0 — «программа завершилась нормально»
}
```
#include <файл.h> — вставляет в программу заголовочный файл (.h) с описаниями библиотечных функций. Сами функции лежат в библиотечных файлах (.lib).
iostream.h — ввод-вывод: cout (вывод, «си-аут»), cin (ввод), endl (конец строки).
conio.h — консоль: getch() ждёт клавишу и не показывает её, clrscr() очищает экран.
Переменные объявляют в любом месте, но до первого использования.
! Как в тесте: math.h — математика: sqrt, pow, sin, fabs…

В C++Builder консольную программу создают так: File → New → Other… → Console Wizard. Builder сам пишет заготовку с #include <vcl.h>, #pragma hdrstop и int main(int argc, char* argv[]) — подробно в лабе 1 ниже.

Русский текст в консоли. Окно консоли Windows по умолчанию работает в кодировке 866, а Builder сохраняет строки в 1251 — русские буквы превращаются в «кракозябры». Поэтому в примерах лаб подсказки пишут латиницей: "Vvedite x: ". На этом сайте русский текст показывается нормально.

! Вопрос УМКД: **Общая структура программы на C++?** — Директивы препроцессора (#include), глобальные объявления, функции; обязательна main() — с неё начинается выполнение; тело функции в { }, операторы через ;, в конце return 0;.

## 9. Типы данных
**Простые типы (Borland C++Builder, 32 бита)**
| Тип | Байт | Диапазон | Пример |
| char | 1 | −128 … 127 | символ: char c = 'A'; |
| unsigned char | 1 | 0 … 255 |
| short (short int) | 2 | −32 768 … 32 767 |
| unsigned short | 2 | 0 … 65 535 |
| int | 4 | −2 147 483 648 … 2 147 483 647 | целое: int n = 5; |
| unsigned int | 4 | 0 … 4 294 967 295 |
| long (long int) | 4 | как int |
| float | 4 | ±3.4·10±38, 7 цифр | вещественное одинарной точности |
| double | 8 | ±1.7·10±308, 15 цифр | вещественное двойной точности |
| long double | 10 | ±3.4·10±4932, 19 цифр |
| bool | 1 | true / false (1 / 0) | логический: bool ok = true; |
| void | — | «нет значения» | функция ничего не возвращает |

Модификаторы меняют размер и знак: signed / unsigned (со знаком / без знака), short / long. В C++ true — это 1, false — 0, а любое ненулевое число в условии считается истиной.

Переполнение. Если значение выходит за диапазон, оно «перескакивает» на другой конец: short s = 32767; s++; → −32768. Ошибки нет — программа молча считает неправильно. ## Enum, массивы, указатели (кратко — подробно в темах 2 и 4)

Перечислимый тип enum — свой тип с именованными целыми константами:

```
enum Color { RED, GREEN, BLUE };      // RED = 0, GREEN = 1, BLUE = 2
enum Day { MON = 1, TUE, WED };        // TUE = 2, WED = 3 — дальше по +1
Color c = GREEN;
cout << c;                              // напечатает 1
```
Множество однотипных данных (multiplicity) хранят в массиве — последовательности значений одного типа под одним именем: int a[5];, номера (индексы) с 0 до 4. Встроенного типа «множество», как set в Pascal, в C++ нет.

Указатель — переменная, в которой хранится адрес другой переменной в памяти: int x = 5; int *p = &x; — &x «адрес x», *p «значение по адресу».

## Ввод-вывод и переменные

Переменная — именованная область памяти, где хранится значение определённого типа; значение может меняться во время работы программы. Объявление: тип имя; или сразу с начальным значением int n = 0;, несколько сразу: double x, y, z;.

Вывод cout << "x = " << x << endl; — текст в кавычках печатается как есть (он нужен только для понятности), переменная — своим значением. Ввод cin >> x; — программа ждёт, пока пользователь наберёт число и нажмёт Enter. Числа можно вводить и в экспоненциальной форме: -0.423e-2.

Как C++ печатает дробные числа через cout: максимум 6 значащих цифр, лишние нули отбрасываются: 6.9465, 0.333333, 1.23457e+06 (= 1 234 570).
