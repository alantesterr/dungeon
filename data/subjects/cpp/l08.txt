## 1. Объявление класса
**Структура класса**
```
class Rect                        // имя класса — новый тип
{
private:                          // закрытые члены: доступны только методам класса
  double w, h;                    // поля (data members)
public:                           // открытые члены: доступны всем
```
Rect(double a, double b)        // конструктор (тема 13)
```
  { w = a; h = b; }
  double area() { return w * h; } // метод (member function), описан внутри
  void show();                    // только объявлен
};                                // ; после } обязательна!
void Rect::show()                 // метод описан вне класса: Класс::метод
{ cout << w << " x " << h << endl; }
```
Поля — переменные класса, методы — функции класса. Вместе — члены класса.
Спецификаторы доступа: public — всем; private — только методам этого класса (по умолчанию в class); protected — этому классу и наследникам (тема 12).
Инкапсуляция в классе: поля делают private, а для работы с ними дают public-методы.
struct — то же, что class, но по умолчанию всё public.

## 2. Создание объектов и доступ к членам
**Объекты**
```
Rect r(3, 4);          // объект в стеке
cout << r.area();      // доступ через точку
Rect *p = &r;          // указатель на объект
cout << p->area();     // доступ через стрелку (= (*p).area())
Rect *q = new Rect(1, 2);   // объект в динамической памяти
q->show(); delete q;
Rect arr[3] = { Rect(1,1), Rect(2,2), Rect(3,3) };   // массив объектов
```
Связь класса и объекта: класс — тип (описание), объект — переменная этого типа. У каждого объекта свои поля, а методы общие.

## 3. Указатель this, статические члены, объекты в функциях
**Дополнение**
this — скрытый указатель внутри метода на объект, для которого метод вызван. Нужен, когда параметр называется как поле: void setW(double w) { this->w = w; }, и чтобы вернуть сам объект: return *this;
static-поле — одно на весь класс (общее для всех объектов), например счётчик созданных объектов. Объявляется в классе static int count; и определяется вне: int Rect::count = 0;. static-метод вызывается без объекта: Rect::getCount(), this в нём нет.
Передача объекта в функцию: по значению (копия), по ссылке void f(Rect &r) (можно менять), по константной ссылке void f(const Rect &r) (без копии и без изменений — тогда вызывать можно только const-методы).
Взаимодействие объектов: метод одного объекта получает другой объект как параметр: a.transfer(b, 100).

## Для теста на английском
A class is a blueprint for creating objects (класс — «чертёж» для создания объектов) с похожими атрибутами и поведением. Ещё одна формулировка из теста: abstractions that describe methods, properties of objects that do not exist yet (абстракции, описывающие методы и свойства ещё не существующих объектов).
An object is an instance of a class (объект — экземпляр класса) в памяти. С помощью конкретного класса создаётся object.
Difference between a class and an object: класс задаёт свойства и поведение (properties and behaviors), объект — конкретный экземпляр (instance) этого класса.
How many objects can be created from one class? — as many as needed (сколько нужно): TDog a, b, c; — три объекта одного класса.
Encapsulation в классах — hiding the implementation details of a class and only exposing the necessary interfaces (скрыть детали реализации, наружу открыть только нужное): поля в private, методы для работы с ними в public.

Отличия C++ от C: операции new/delete (p = new int(5); q = new int[10]; delete p; delete [] q;); переменную можно объявить прямо в for (int i = 0; …); параметры по умолчанию — только в конце списка: void f(int a, int b, int c = 1);; тип bool (true/false); ссылки int &b = a; — второе имя переменной, обязательно инициализируется и потом не меняется; cin >> x; cout << x << endl;; пространства имён namespace A {…} и операция :: (A::x, ::c — глобальная c), using namespace std;.

| Область доступа | Кто видит |
| private | только методы самого класса (по умолчанию в class) |
| public | любой код (по умолчанию в struct) |
| protected | методы класса и его наследников |
class и struct отличаются только доступом по умолчанию (и видом наследования по умолчанию). Порядок и число секций private/public/protected — любые.
Доступ к членам: через объект или ссылку — точка x1.f(); через указатель — стрелка p->f().
Селекторы (getters) и модификаторы (setters) — методы, через которые читают и меняют закрытые поля согласованно.
Метод можно определить в классе (тогда он inline) или вне класса через ::: int X::func1() { … }. inline — рекомендация компилятору вставить код функции на место вызова.
this — скрытый указатель на текущий объект, неявный параметр каждого метода. Вернуть сам объект: return *this;.
static-поле — одно на все объекты класса (например, счётчик объектов); его обязательно ещё раз объявляют вне класса: int B::i = 10;. static-метод не имеет this, вызывается через класс: B::f(1);.
const-метод int get() const { … } не может менять поля объекта. У константного объекта const X x2 = x1; можно вызывать только const-методы.
friend — функция или класс, не член класса, но с доступом к его private-полям: friend void func(B &, D &);, friend class X;.
Перегрузка операций: complex operator+(const complex &y);. Нельзя перегружать . :: ?: .* # sizeof typeid. Операцию = перегружают только методом класса. Вывод << перегружают функцией-другом: friend ostream& operator<<(ostream &out, const complex c);.
Перегрузка функций — несколько функций с одним именем в одной области видимости и разными параметрами. Компилятор выбирает по порядку: точное совпадение → расширения (char → int, float → double) → стандартные преобразования → преобразования пользователя → «…».

## Вопросы УМКД к теме 8 — с ответами
- **Что такое класс в C++?** — Пользовательский тип, объединяющий поля (данные) и методы (функции); объявляется словом class.
- **Что такое объект?** — Экземпляр класса — переменная типа класса со своими значениями полей.
- **Связь класса и объекта?** — Класс — описание (тип), объект — конкретный экземпляр, созданный по этому описанию; по одному классу — сколько угодно объектов.
- **Что такое поля и методы класса?** — Поля (data members) — переменные класса, хранят состояние; методы (member functions) — функции класса, задают поведение.
- **Как объявить класс в C++?** — class Имя { private: поля; public: методы; }; — с точкой с запятой в конце.
- **Что такое спецификаторы public, private, protected?** — public — доступ всем; private — только методам самого класса; protected — методам класса и его наследников.
- **Что такое инкапсуляция в классе C++?** — Поля делаются private, работа с ними — через public-методы, которые проверяют данные.
- **Как создать объект?** — Объявить переменную типа класса: Rect r;, Rect r(3,4); или динамически: Rect *p = new Rect(3,4);
- **Как обратиться к членам класса?** — Через точку у объекта (r.area()) или через стрелку у указателя (p->area()); внутри методов — просто по имени.
- **Назначение указателя this?** — Скрытый указатель на текущий объект внутри метода; нужен, чтобы отличить поле от параметра с тем же именем и вернуть сам объект (*this).
- **Что такое статические члены класса?** — Члены, общие для всех объектов класса (static); static-поле определяется вне класса, static-метод вызывается через Класс::метод() без объекта.
- **Как объекты одного класса взаимодействуют друг с другом?** — Метод одного объекта получает другой объект (обычно по ссылке) и вызывает его методы или читает его поля — внутри класса доступны даже private-поля другого объекта того же класса.
