## Выражение, операция, операнд
! Дополнение: выражение
**Выражение** — запись из **операндов** (переменных, констант, вызовов функций), **знаков операций** и скобок, которая вычисляется в значение определённого типа. В `s = a + 15`: операнды a, 15, s; операции + и =.
Операции бывают **унарные** (один операнд: `-x`, `!a`, `++i`), **бинарные** (два: `a + b`) и одна **тернарная** (три: `a ? b : c`).

## Арифметика
! Дополнение: арифметические операции
| Операция | Смысл | Пример | Результат |
| `+ - *` | сложение, вычитание, умножение | `7*2` | 14 |
| `/` | деление. **Целое / целое = целое** (дробь отбрасывается) | `7/2`, `7/2.0` | 3 и 3.5 |
| `%` | остаток от деления, **только для целых** | `7%2`, `-7%3` | 1 и −1 |
| `++` | инкремент: +1 | `i++`, `++i` |  |
| `--` | декремент: −1 | `i--`, `--i` |  |
**Префикс и постфикс.** `++i` — сначала увеличить, потом использовать значение. `i++` — сначала использовать старое значение, потом увеличить. `int i=10; cout<<i++;` напечатает 10 (i стало 11), а затем `cout<<++i;` напечатает 12. Инкремент применяют только к переменным, не к константам и выражениям.
Целую часть от деления (как div в Pascal) даёт `/` для целых, остаток (mod) — `%`. Для дробных остаток — функция `fmod(x,y)`.

## Сравнение и логика
! Дополнение: сравнение, логика, истина
Сравнения: `==` (равно), `!=` (не равно), `< > <= >=`. Результат — **true (1)** или **false (0)**. Знак `=` — это присваивание, а не сравнение: `if (x = 5)` присвоит 5 и всегда будет истиной.
Логические: `&&` — «И» (логическое умножение), `||` — «ИЛИ» (логическая сумма), `!` — «НЕ» (отрицание). В C++ **0 — ложь, любое не 0 — истина**; true = 1, false = 0.
| a | b | a && b | a || b | !a |
| 0 | 0 | 0 | 0 | 1 |
| 0 | 1 | 0 | 1 | 1 |
| 1 | 0 | 0 | 1 | 0 |
| 1 | 1 | 1 | 1 | 0 |
**Сокращённое вычисление:** в `a && b` b не вычисляется, если a ложно; в `a || b` — если a истинно.
Двойное неравенство 0 < x < 10 пишут так: `x > 0 && x < 10`. Запись `0 < x < 10` компилируется, но означает `(0 < x) < 10` — всегда истина.

## Присваивание в стиле C
! Дополнение: присваивание
| Запись | Равносильно |
| `s += x` | `s = s + x` |
| `s -= x` | `s = s - x` |
| `s *= x` | `s = s * x` — «умножить и присвоить» |
| `s /= x` | `s = s / x` |
| `n %= 3` | `n = n % 3` |
| `a &= b, a |= b, a ^= b, a <<= 1, a >>= 1` | побитовые |
Справа сначала вычисляется всё выражение: `x=2; x *= (x+1);` → x = 2·3 = 6. Присваивание само имеет значение, поэтому можно `a = b = c = 0;` (справа налево).

## Побитовые операции, запятая, ?:, sizeof, ::, . и ->
! Дополнение: остальные операции
- **Побитовые** (над каждым битом целого): `&` И, `|` ИЛИ, `^` исключающее ИЛИ, `~` инверсия, `<<` сдвиг влево (×2), `>>` вправо (÷2). 5 & 3 = 0101 & 0011 = 0001 = 1; 5 | 3 = 7; 5 ^ 3 = 6; 1 << 4 = 16.
- **Запятая**: вычисляет выражения слева направо, значение — последнее. `for (i=0, j=10; i<j; i++, j--)`.
- **Условная (тернарная) операция** `условие ? выражение1 : выражение2` — простейшее «если». `max = a > b ? a : b;` Вложенная: `s = x>0 ? 1 : (x<0 ? -1 : 0);`
- **sizeof** — размер в байтах: `sizeof(int)` = 4, `sizeof(x)`, для массива — весь размер. Запись: `sizeof (type)`.
- **::** — разрешение области видимости: `::g` — глобальная g, когда есть локальная с тем же именем; `Book::show` — метод класса.
- **.** и **->** — доступ к полю/методу объекта: `obj.name` для объекта, `p->name` для указателя на объект (= `(*p).name`).

## Работа с памятью. Указатели (лекция 6 преподавателя)
**Оригинал слайдов (на английском — перевод ниже)**
**6.1 Subject: Pointers in C++.** The purpose of a lesson is to learn the basic principles of using pointers in C++.
Every variable is a memory location and every memory location has its address defined. A **pointer** is a variable whose value is the address of another variable. Like any variable or constant, a pointer must be declared before using it in a program. The general form of a pointer variable declaration: `type *var-name;` Where, **type** is the pointer's base type (the type of a value that is stored in a cell); **var-name** is the name of the pointer variable.
Some valid pointer declarations: `int *ip; double *dp; float *fp; char *ch;` The actual data type of the value of all pointers (whether integer, float, character, or otherwise) is the same, a long hexadecimal number that represents a memory address. The only difference between pointers of different data types is the data type of the variable or constant that the pointer points to.
**Pointers: reference operator (&).** To know where the data is stored, C++ has an & operator. The & (reference) operator gives you the address occupied by a variable. If a1 is a variable then, &a1 gives the address of that variable in a memory.
**Pointers: dereference operator (*).** To get the value stored in the memory address, we use the dereference operator (* - asterisk).
**Pointers and arrays.** Let's see the example: `int A[4]; int *ptr;` Suppose, we need to hold the address of third element of an array, i.e. we need the pointer ptr to point to third array's element.
**Solve the problems:** Define the array of 10 integers. Create 2 pointers and set the address of first arrays element into first pointer, the last arrays element into second pointer. Define the array of 100 real numbers. Output the addresses of all arrays elements.
Каждая переменная — это участок памяти, и у каждого участка есть адрес. **Указатель** — переменная, значение которой — адрес другой переменной. Как любую переменную, указатель нужно объявить до использования: `тип *имя;`, где тип — базовый тип указателя (тип значения в ячейке), имя — имя указателя.
Правильные объявления: `int *ip; double *dp; float *fp; char *ch;` Сам адрес у всех указателей одинаковый по виду — длинное шестнадцатеричное число. Разница только в типе того, на что указатель указывает.
**Операция взятия адреса &** показывает, где лежит переменная: если a1 — переменная, то &a1 — её адрес в памяти. **Операция разыменования *** даёт значение, которое лежит по адресу.
```
int *pc, c;
c = 5;
pc = &c;
cout << "Address that pointer pc holds: " << pc << endl;
cout << "Content of the address pointer pc holds: " << *pc << endl;
```
! Дополнение: указатели простыми словами
- Память — длинная улица из байтов, у каждого номер (адрес). `int x` занимает 4 байта, и `&x` — номер первого.
- `int *p = &x;` — p хранит адрес x. `*p = 10;` — записать 10 туда, куда смотрит p, то есть в x.
- **Через указатель можно менять переменную**, не называя её по имени — так функции меняют чужие переменные (тема 5).
- **Указатели и массивы.** Имя массива — адрес его первого элемента: `int *p = A;` — то же, что `&A[0]`. `p+2` — адрес A[2] (сдвиг на 2 элемента, а не на 2 байта), `*(p+2)` = `A[2]` = `p[2]`.
- Адрес третьего элемента: `ptr = &A[2];` (нумерация с 0!).
- `NULL` (0) — «указатель никуда». Разыменовывать его нельзя — программа упадёт (Access violation).
- В Borland `cout << p` печатает адрес **десятичным числом**, например 1769276, а `printf("%p", p)` — шестнадцатеричным 001AFF3C. Адреса при каждом запуске могут быть другими.
- **Динамическая память:** `int *a = new int[n];` — массив нужного размера во время работы; освобождать `delete[] a;`

## Что такое выражение в C++?
**Ответ из УМКД:** Запись из операндов, знаков операций и скобок, которая вычисляется в значение определённого типа:
a + b*2
.
Выражение — «формула» на C++, которая в итоге даёт одно значение: `a + b*2`, `x*x`, `sqrt(pow(5,4))`. Тип результата зависит от операндов: если смешать типы, результат берёт **более вместительный** (int + float → float, float + double → double, short + int → int), чтобы ничего не потерять.
Считай выражения по шагам: `x=0; x++; x=x+1; x=x*x;` → 0 → 1 → 2 → 4.

## Что такое операции и операнды?
**Ответ из УМКД:** Операция — действие (+, *, =, &&…), операнд — то, над чем действие выполняется (переменная, константа, результат другой операции).
**Операция** — действие: `+ - * / % = ++ -- && ! sizeof`. **Операнд** — то, над чем действие: переменная, число, результат другой операции.
**Унарные** операции берут один операнд: `++` (инкремент, +1), `--` (декремент, −1), `!`, `-x`. Инкремент меняет значение, поэтому применяется только к **переменным**.
`i++` (постфикс) — сначала отдаёт старое значение, потом увеличивает; `++i` (префикс) — сначала увеличивает, потом отдаёт. `int i=10; cout<<i++; cout<<++i;` → 10, 12.
`sizeof(тип)` — размер в байтах, пишется со скобками.

## Какие арифметические операции есть в C++?
**Ответ из УМКД:** + - * / %
, а также
++
и
--
. Деление целых даёт целое, % — только для целых.
`+ - * /` и `%` (остаток). Главная ловушка: **целое / целое = целое**, дробь отбрасывается: `7/2 = 3`, `5/2 = 2`, `7/3 = 2`. Чтобы получить дробь — сделай одно число дробным: `7.0/2 = 3.5`, `pow(x, 1/5.)` (без точки `1/5 = 0`).
`%` — остаток, только для целых: `7%2 = 1`, `5%2 = 1`. Пара «/ и %» = «div и mod» из Pascal.

## Какие операции сравнения и логические используются?
**Ответ из УМКД:** Сравнения
== != < > <= >=
; логические
&&
(И),
||
(ИЛИ),
!
(НЕ). Результат — true (1) или false (0).
Сравнения: `== != < > <= >=`. Внимание: `=` — это присваивание, а сравнение — `==`.
Логические: `&&` — И («логическое умножение»: 1·0 = 0), `||` — ИЛИ («логическая сумма»), `!` — НЕ. Одинарные `&` и `|` — побитовые, это другое.
Результат условия — **1 (true, истина)** или **0 (false, ложь)**; любое не-ноль считается истиной. `(1 != 1)` → 0.
Условная операция: `max = (a > b) ? a : b;`

## Что такое присваивание и составное присваивание?
**Ответ из УМКД:** =
записывает значение в переменную; составное
+= -= *= /= %=
— сокращение:
s += x
≡
s = s + x
.
`=` кладёт значение справа в переменную слева. Составное присваивание — сокращение:
| Коротко | Полностью |
| `s += x` | `s = s + x` |
| `x *= 3` | `x = x * 3` |
| `n %= 3` | `n = n % 3` |
`x *= (x+1)` при x=2 → 2·3 = 6. `x *= 1` значение не меняет.

## Что такое приоритет и ассоциативность операций?
**Ответ из УМКД:** Приоритет — какая операция выполняется раньше (* раньше +); ассоциативность — порядок для одинакового приоритета: обычно слева направо, у присваивания и унарных — справа налево. Скобки меняют порядок.
Приоритет — что считается раньше: сначала скобки, потом унарные (`! ++ --`), потом `* / %`, потом `+ -`, потом сравнения, потом `&&`, потом `||`, и в самом конце присваивание. Одинаковые по приоритету — слева направо (присваивание — справа налево).
`k=(3/2)*(3%2)`: скобки → 1 и 1 → 1. При смешивании типов результат «повышается»: short→int→long→float→double.

## Что такое директива препроцессора? Зачем #include?
**Ответ из УМКД:** Команда препроцессору, выполняется до компиляции, начинается с #.
#include <файл.h>
вставляет заголовочный файл с описаниями библиотечных функций.
Директива препроцессора начинается с `#` и выполняется **до компиляции**. `#include <iostream.h>` вставляет заголовочный файл (**.h** — header) с описаниями функций; сами функции лежат в **библиотечных файлах**.
`iostream.h` — `cin >>` (ввод) и `cout <<` (вывод); `conio.h` — `clrscr`, `getch`; `stdlib.h` — случайные числа; `stdio.h` — файлы и printf.

## Что такое память компьютера и как в ней хранятся данные?
**Ответ из УМКД:** Последовательность пронумерованных байтов; номер — адрес. Переменная занимает несколько подряд идущих байтов (int — 4) в двоичном виде.
Память — ряд пронумерованных байтов, номер байта — **адрес**. Переменная занимает несколько байтов подряд: `char` 1, `short` 2, `int` 4, `float` 4, `double` 8. Размер узнают через `sizeof(тип)`.
Значения в память кладут вводом `cin >> x` или присваиванием.

## Что такое указатель?
**Ответ из УМКД:** Переменная, в которой хранится адрес другой переменной:
int *p = &x;
Указатель — переменная, где хранится **адрес** другой переменной: `int *p = &x;`. Звёздочка при объявлении говорит «это указатель на int».

## В чём разница между операциями & и *?
**Ответ из УМКД:** &x
— взять адрес переменной;
*p
— взять значение по адресу (разыменование). Они обратные:
*&x
= x.
`&x` — «где лежит x» (адрес). `*p` — «что лежит по адресу p» (значение). Они обратные: `*&x == x`.
```
int x = 5;
int *p = &x;   // p хранит адрес x
*p = 10;       // меняем x через указатель — теперь x == 10
```

## Как обратиться к переменной через указатель?
**Ответ из УМКД:** Записать адрес в указатель
p = &x;
, затем читать и менять через
*p
:
*p = 10;
меняет x.
Сначала записать адрес: `p = &x;`, потом работать через `*p`: `*p = *p * 2;` удвоит x, не называя его по имени. С массивом: `int *p = &a[0];` (или `p = a`), `*(p+i)` — это `a[i]`.

## Указатели простыми словами
Память — длинная улица из байтов, у каждого номер (адрес). int x занимает 4 байта, и &x — номер первого.
int *p = &x; — p хранит адрес x. *p = 10; — записать 10 туда, куда смотрит p, то есть в x.
Через указатель можно менять переменную, не называя её по имени — так функции меняют чужие переменные (тема 5).
Указатели и массивы. Имя массива — адрес его первого элемента: int *p = A; — то же, что &A[0]. p+2 — адрес A[2] (сдвиг на 2 элемента, а не на 2 байта), *(p+2) = A[2] = p[2].
Адрес третьего элемента: ptr = &A[2]; (нумерация с 0!).
NULL (0) — «указатель никуда». Разыменовывать его нельзя — программа упадёт (Access violation).
В Borland cout << p печатает адрес десятичным числом, например 1769276, а printf("%p", p) — шестнадцатеричным 001AFF3C. Адреса при каждом запуске могут быть другими.
Динамическая память: int *a = new int[n]; — массив нужного размера во время работы; освобождать delete[] a;
