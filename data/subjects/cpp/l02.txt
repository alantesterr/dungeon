## 1. Выражение, операция, операнд
**Выражение**

Выражение — запись из операндов (переменных, констант, вызовов функций), знаков операций и скобок, которая вычисляется в значение определённого типа. В s = a + 15: операнды a, 15, s; операции + и =.

Операции бывают унарные (один операнд: -x, !a, ++i), бинарные (два: a + b) и одна тернарная (три: a ? b : c).

! Вопрос УМКД: **Что такое выражение в C++?** — Запись из операндов, знаков операций и скобок, которая вычисляется в значение определённого типа: a + b*2.
! Вопрос УМКД: **Что такое операции и операнды?** — Операция — действие (+, *, =, &&…), операнд — то, над чем действие выполняется (переменная, константа, результат другой операции).

## 2. Арифметика
**Арифметические операции**
| Операция | Смысл | Пример | Результат |
| + - * | сложение, вычитание, умножение | 7*2 | 14 |
| / | деление. Целое / целое = целое (дробь отбрасывается) | 7/2, 7/2.0 | 3 и 3.5 |
| % | остаток от деления, только для целых | 7%2, -7%3 | 1 и −1 |
| ++ | инкремент: +1 | i++, ++i |
| -- | декремент: −1 | i--, --i |

Префикс и постфикс. ++i — сначала увеличить, потом использовать значение. i++ — сначала использовать старое значение, потом увеличить. int i=10; cout<<i++; напечатает 10 (i стало 11), а затем cout<<++i; напечатает 12. Инкремент применяют только к переменным, не к константам и выражениям.

Целую часть от деления (как div в Pascal) даёт / для целых, остаток (mod) — %. Для дробных остаток — функция fmod(x,y).

! Вопрос УМКД: **Какие арифметические операции есть в C++?** — + - * / %, а также ++ и --. Деление целых даёт целое, % — только для целых.

## 3. Сравнение и логика
**Сравнение, логика, истина**

Сравнения: == (равно), != (не равно), < > <= >=. Результат — true (1) или false (0). Знак = — это присваивание, а не сравнение: if (x = 5) присвоит 5 и всегда будет истиной.

Логические: && — «И» (логическое умножение), || — «ИЛИ» (логическая сумма), ! — «НЕ» (отрицание). В C++ 0 — ложь, любое не 0 — истина; true = 1, false = 0.

| a | b | a && b | a || b | !a |
| 0 | 0 | 0 | 0 | 1 |
| 0 | 1 | 0 | 1 | 1 |
| 1 | 0 | 0 | 1 | 0 |
| 1 | 1 | 1 | 1 | 0 |

Сокращённое вычисление: в a && b b не вычисляется, если a ложно; в a || b — если a истинно.

Двойное неравенство 0 < x < 10 пишут так: x > 0 && x < 10. Запись 0 < x < 10 компилируется, но означает (0 < x) < 10 — всегда истина.

! Вопрос УМКД: **Какие операции сравнения и логические используются?** — Сравнения == != < > <= >=; логические && (И), || (ИЛИ), ! (НЕ). Результат — true (1) или false (0).

## 4. Присваивание в стиле C
**Присваивание**
| Запись | Равносильно |
| s += x | s = s + x |
| s -= x | s = s - x |
| s *= x | s = s * x — «умножить и присвоить» |
| s /= x | s = s / x |
| n %= 3 | n = n % 3 |
| a &= b, a |= b, a ^= b, a <<= 1, a >>= 1 | побитовые |

Справа сначала вычисляется всё выражение: x=2; x *= (x+1); → x = 2·3 = 6. Присваивание само имеет значение, поэтому можно a = b = c = 0; (справа налево).

! Вопрос УМКД: **Что такое присваивание и составное присваивание?** — = записывает значение в переменную; составное += -= *= /= %= — сокращение: s += x ≡ s = s + x.

## 5. Побитовые операции, запятая, ?:, sizeof, ::, . и ->
**Остальные операции**
Побитовые (над каждым битом целого): & И, | ИЛИ, ^ исключающее ИЛИ, ~ инверсия, << сдвиг влево (×2), >> вправо (÷2). 5 & 3 = 0101 & 0011 = 0001 = 1; 5 | 3 = 7; 5 ^ 3 = 6; 1 << 4 = 16.
Запятая: вычисляет выражения слева направо, значение — последнее. for (i=0, j=10; i<j; i++, j--).
Условная (тернарная) операция условие ? выражение1 : выражение2 — простейшее «если». max = a > b ? a : b; Вложенная: s = x>0 ? 1 : (x<0 ? -1 : 0);
sizeof — размер в байтах: sizeof(int) = 4, sizeof(x), для массива — весь размер. Запись: sizeof (type).
:: — разрешение области видимости: ::g — глобальная g, когда есть локальная с тем же именем; Book::show — метод класса.
. и -> — доступ к полю/методу объекта: obj.name для объекта, p->name для указателя на объект (= (*p).name).

## 6. Приоритет и преобразование типов
**Приоритет (сверху — выше)**
| Операции | Порядок |
::
| () [] . -> x++ x-- | слева направо |
| ++x --x ! ~ -x +x *p &x (тип) sizeof new delete | справа налево |
| * / % | слева направо |
| + - | слева направо |
<< >>
< <= > >=
== !=
&, затем ^, затем |
&&, затем ||
| ?: | справа налево |
| = += -= *= … | справа налево |
| , | слева направо |

Преобразование типов в выражениях. Если операнды разных типов, «меньший» тип превращается в «больший»: char, short → int; int → long → float → double. float + double = double, long + float = float, short + int = int. Поэтому 7/2.0 = 3.5. Явное приведение: (double)a/b, (int)3.99 = 3 (дробь отбрасывается, не округляется).

! Вопрос УМКД: **Что такое приоритет и ассоциативность операций?** — Приоритет — какая операция выполняется раньше (* раньше +); ассоциативность — порядок для одинакового приоритета: обычно слева направо, у присваивания и унарных — справа налево. Скобки меняют порядок.

## 7. Дополнительные библиотеки
**Что в каком заголовке (Borland C++Builder 6)**

Директива препроцессора — команда, которая выполняется до компиляции и начинается с #. #include <файл> вставляет заголовочный файл (.h) с прототипами функций; сами функции лежат в библиотечных файлах (.lib) и подключаются компоновщиком.

| Заголовок | Что даёт |
| iostream.h | cout << вывод, cin >> ввод, endl |
| iomanip.h | setw(n) ширина, setprecision(n) точность, setiosflags(ios::fixed) |
| stdio.h | printf, scanf, puts, gets, getchar, sprintf; файлы fopen, fclose, fprintf, fscanf, fgets, fputs |
| conio.h | getch() — ждать клавишу (без показа), clrscr() — очистить экран, textcolor, cprintf, gotoxy |
| math.h | sqrt, pow, sin, cos, tan, asin, acos, atan, exp, log, log10, fabs, ceil, floor, fmod, константа M_PI |
| stdlib.h | rand(), srand, random(n), randomize(), abs, atoi, atof, itoa, exit |
| string.h | строковые функции strlen, strcpy, strcat, strcmp… (тема 6) |
| ctype.h | isdigit, isalpha, toupper, tolower |
| time.h | time(NULL) |

Случайные числа в Borland: random(n) даёт целое от 0 до n−1. Диапазон [a; b] — random(b-a+1)+a; например [−20; 50] — random(70)-20 (так в базе тестов; строго нужно random(71)−20). randomize(); запускает генератор от часов, чтобы при каждом запуске числа были разные.

Форматы printf: %d целое, %f вещественное, %e экспоненциальная форма, %c символ, %s строка, %u беззнаковое, %o восьмеричное, %x шестнадцатеричное. %.2f — 2 знака после точки, %5d — ширина 5. Для scanf перед переменной ставят &: scanf("%d", &x);

Округление: ceil(3.226) = 4 (вверх), floor(3.63) = 3 (вниз). Модуль: abs — для целых, fabs — для дробных.

Работа с памятью. Указатели (лекция 6 преподавателя)
Каждая переменная — это участок памяти, и у каждого участка есть адрес. Указатель — переменная, значение которой — адрес другой переменной. Как любую переменную, указатель нужно объявить до использования: тип *имя;, где тип — базовый тип указателя (тип значения в ячейке), имя — имя указателя.

Правильные объявления: int *ip; double *dp; float *fp; char *ch; Сам адрес у всех указателей одинаковый по виду — длинное шестнадцатеричное число. Разница только в типе того, на что указатель указывает.

Операция взятия адреса & показывает, где лежит переменная: если a1 — переменная, то &a1 — её адрес в памяти. Операция разыменования * даёт значение, которое лежит по адресу.

```
int *pc, c;
c = 5;
pc = &c;
cout << "Address that pointer pc holds: " << pc << endl;
cout << "Content of the address pointer pc holds: " << *pc << endl;
```

! Вопрос УМКД: **Что такое дополнительные библиотеки и зачем они нужны?** — Готовые наборы функций: math.h (математика), stdio.h (printf/scanf, файлы), conio.h (консоль), stdlib.h (случайные числа, преобразования), string.h (строки). Не нужно писать всё самому.
! Вопрос УМКД: **Что такое директива препроцессора? Зачем #include?** — Команда препроцессору, выполняется до компиляции, начинается с #. #include <файл.h> вставляет заголовочный файл с описаниями библиотечных функций.

## Указатели простыми словами
Память — длинная улица из байтов, у каждого номер (адрес). int x занимает 4 байта, и &x — номер первого.
int *p = &x; — p хранит адрес x. *p = 10; — записать 10 туда, куда смотрит p, то есть в x.
Через указатель можно менять переменную, не называя её по имени — так функции меняют чужие переменные (тема 5).
Указатели и массивы. Имя массива — адрес его первого элемента: int *p = A; — то же, что &A[0]. p+2 — адрес A[2] (сдвиг на 2 элемента, а не на 2 байта), *(p+2) = A[2] = p[2].
Адрес третьего элемента: ptr = &A[2]; (нумерация с 0!).
NULL (0) — «указатель никуда». Разыменовывать его нельзя — программа упадёт (Access violation).
В Borland cout << p печатает адрес десятичным числом, например 1769276, а printf("%p", p) — шестнадцатеричным 001AFF3C. Адреса при каждом запуске могут быть другими.
Динамическая память: int *a = new int[n]; — массив нужного размера во время работы; освобождать delete[] a;

! Вопрос УМКД: **Что такое память компьютера и как в ней хранятся данные?** — Последовательность пронумерованных байтов; номер — адрес. Переменная занимает несколько подряд идущих байтов (int — 4) в двоичном виде.
! Вопрос УМКД: **Что такое указатель?** — Переменная, в которой хранится адрес другой переменной: int *p = &x;
! Вопрос УМКД: **В чём разница между операциями & и *?** — &x — взять адрес переменной; *p — взять значение по адресу (разыменование). Они обратные: *&x = x.
! Вопрос УМКД: **Как обратиться к переменной через указатель?** — Записать адрес в указатель p = &x;, затем читать и менять через *p: *p = 10; меняет x.
