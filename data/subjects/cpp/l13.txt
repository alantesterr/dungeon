## Конструктор

Конструктор — специальный метод, который вызывается один раз автоматически при создании объекта и инициализирует его поля. Имя = имя класса, типа результата нет (даже void).

```
class Book
{
  string title; int year;
public:
  Book() : title("Unknown"), year(0) {}                  // по умолчанию (без параметров)
  Book(string t, int y) { title = t; year = y; }         // с параметрами
  Book(const Book &b) { title = b.title; year = b.year; } // копирования
  ~Book() { cout << "~Book " << title << endl; }        // деструктор
};
Book a;                    // Book()
Book b("1984", 1949);      // Book(string, int)
Book c = b;                // конструктор копирования
Book *p = new Book("X", 2000);  …  delete p;   // деструктор при delete
```
По умолчанию — без параметров (или все с умолчаниями). Если не написать ни одного конструктора, компилятор создаст пустой. Если написан только конструктор с параметрами — Book a; уже нельзя.
Список инициализации : title("Unknown"), year(0) — поля инициализируются до входа в тело; обязателен для const-полей, ссылок и вызова конструктора базового класса.
Перегрузка конструкторов — несколько конструкторов с разными параметрами; выбирается по аргументам.
Конструктор копирования Класс(const Класс &) вызывается, когда объект создаётся из другого: Book c = b;, передача объекта в функцию по значению, возврат по значению.
Когда вызывается конструктор: при объявлении объекта, при new, при создании временного объекта Book("A", 1), для каждого элемента массива объектов.

## Деструктор и время жизни

Деструктор ~Имя() — вызывается автоматически при уничтожении объекта: без параметров и типа, один на класс. Назначение — освободить ресурсы: память, выделенную через new (delete[]), открытые файлы.

Когда вызывается: локальный объект — при выходе из блока { } (в обратном порядке создания); глобальный — после завершения main; динамический — при delete; параметр по значению — при выходе из функции.

Жизненный цикл объекта: выделение памяти → конструктор → использование (вызов методов) → деструктор → освобождение памяти.

## Для теста на английском
Constructor (конструктор) — a special method that is called once when a class' instance is created (вызывается один раз при создании объекта). The initialization of all elements of a class is made in the constructor — начальные значения полей задают в конструкторе.
Destructor (деструктор) — вызывается при уничтожении объекта, имя с тильдой: ~TBook(). У формы: __fastcall ~TForm1();

Конструктор — «то, что область памяти превращает в объект» (Страуструп). Имя = имя класса, тип результата не пишут. Деструктор ~Имя() — без параметров, один на класс.

| Вид конструктора | Прототип для класса X | Пример объявления объекта |
| умолчания (без параметров) | X() или все параметры по умолчанию | X x1; |
| преобразования (один параметр другого типа) | X(T), X(T&), X(const T&) | box b3(5); |
| копирования | X(X&), X(const X&) | box b6 = b5; или box b7(b5); |
| с двумя и более параметрами | X(int, int, int) | box b2(1,2,3); |
explicit запрещает неявный вызов конструктора преобразования: без него stack st1 = 15; молча создаст стек на 15 элементов.
Поверхностное копирование — почленное копирование полей (так работает конструктор копирования, который компилятор создаёт сам). Если в классе есть память из new, нужно глубокое копирование: выделить новую память и скопировать содержимое, иначе два объекта будут указывать на один массив.
box b2 = b3; при объявлении — конструктор копирования; b2 = b3; для уже созданного — операция присваивания (её тоже придётся перегрузить для глубокого копирования).
Что создаётся само: если нет ни одного конструктора — пустой конструктор умолчания; если описан хоть один конструктор — конструктора умолчания уже не будет. Конструктор копирования (поверхностный) и пустой деструктор создаются всегда, если их не описали.
Список инициализации Point(int x1, int y1) : x(x1), y(y1) {} — единственный способ вызвать конструктор с параметрами для поля-объекта и для базового класса. Писать Point p2(2,3); прямо в описании класса нельзя.
Порядок вызова конструкторов: базовые классы → поля-объекты (в порядке объявления в классе) → собственный конструктор. Деструкторы — в обратном порядке.
Конструктор копирования вызывается: при инициализации объекта другим объектом; временным объектом box c = box(3,4,5);; при передаче объекта в функцию по значению; при возврате объекта из функции.
Деструктор вызывается: при выходе из блока, где объявлен объект; для временных объектов сразу после выражения; при delete; при завершении программы — для глобальных и static-объектов.
Для массива объектов X *x1 = new X[10]; нужен конструктор умолчания, а удалять надо delete [] x1;.

## Вопросы УМКД к теме 13 — с ответами
- **Что такое пользовательский класс?** — Класс, созданный программистом для своей задачи (Book, Student), а не взятый из библиотеки.
- **Основные части пользовательского класса?** — Поля (данные), методы, конструкторы, деструктор, спецификаторы доступа.
- **Что такое конструктор?** — Специальный метод с именем класса и без типа результата, автоматически вызывается при создании объекта.
- **Назначение конструктора?** — Инициализировать поля объекта и подготовить его к работе (выделить ресурсы).
- **Что такое конструктор по умолчанию?** — Конструктор без параметров (или со всеми параметрами по умолчанию): Book().
- **Что такое конструктор с параметрами?** — Конструктор, принимающий значения для инициализации полей: Book(string t, int y).
- **Что такое конструктор копирования?** — Конструктор вида Класс(const Класс &), создаёт объект как копию другого.
- **Что такое перегрузка конструкторов?** — Несколько конструкторов в классе с разными параметрами; нужный выбирается по аргументам.
- **Когда вызывается конструктор?** — При создании объекта: объявление переменной, new, временный объект, элементы массива, передача по значению (копирования).
- **Что такое деструктор?** — Специальный метод ~Имя() без параметров и типа, вызывается автоматически при уничтожении объекта.
- **Назначение деструктора?** — Освободить ресурсы объекта: память (delete), файлы и т. п.
- **Когда вызывается деструктор?** — При выходе локального объекта из области видимости (}), при delete, после завершения main для глобальных.
- **Что такое жизненный цикл объекта?** — Создание (память + конструктор) → использование → уничтожение (деструктор + освобождение памяти).
