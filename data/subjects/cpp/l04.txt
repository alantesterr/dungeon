## Цикл с предусловием while
! Дополнение: while
```
while (условие)      // сначала проверка, потом тело
  тело;

int x = 7;
while (x <= 10) { cout << x; x++; }   // x = 7, 8, 9, 10 — 4 раза
```
**Предусловие:** условие проверяется **до** тела. Если сразу ложно — тело не выполнится ни разу. Выход из цикла — когда условие становится ложным. Внутри тела что-то должно менять условие, иначе цикл бесконечный.
**Когда while:** число повторов заранее неизвестно — «пока есть данные», «пока сумма меньше A», «пока число больше 0» (разбор цифр).

## Цикл с постусловием do…while
! Дополнение: do…while
```
do                    // сначала тело, потом проверка
{
  тело;
} while (условие);    // точка с запятой обязательна!

do {
  cout << "n (1..5): "; cin >> n;
} while (n < 1 || n > 5);              // повторять, пока ввод неверный
```
**Постусловие:** тело выполняется **хотя бы один раз**, условие проверяется после. Подходит для ввода с проверкой и меню.
|  | while | do…while |
| Когда проверка | до тела | после тела |
| Минимум выполнений | 0 | 1 |
| Запись | `while (условие) {тело}` | `do {тело} while (условие);` |
В C++ **три** вида циклов: for (с параметром), while (с предусловием), do…while (с постусловием). `repeat … until` — это Pascal.
! Ловушка: **Про базу тестов:** в базе на вопрос «в каком цикле выход происходит, когда условие истинно» правильным отмечен do…while. На самом деле и while, и do…while в C++ выходят, когда условие **ложно**; выход по истине — у repeat…until в Pascal. На тесте выбирай как в базе.

## break и continue
! Дополнение: прерывание цикла
- `break` — немедленно выйти из цикла (и из switch).
- `continue` — пропустить остаток тела и перейти к следующему повтору (в for — к изменению счётчика).
```
for (i = 1; i <= 10; i++)
{
  if (i % 2 == 0) continue;   // чётные пропускаем
  if (i > 7) break;           // после 7 — выход
  cout << i;                  // 1357
}
```
**Цикл без операторов цикла** (вопрос СРС): с помощью `goto` и метки или рекурсии.

## Одномерные массивы
! Дополнение: массив
**Массив** — последовательность значений **одного типа** под одним именем. Элементы связаны тем, что у них одинаковый тип. Номер элемента — **индекс**, нумерация **с 0**.
```
int a[10];                        // 10 целых: a[0] … a[9]
float b[10];                      // массив из 10 вещественных
int c[5] = {1, 2, 3};             // c[3], c[4] = 0
int d[] = {4, 8, 15};             // размер 3 — по количеству значений
const int N = 100; double m[N];   // размер — только константа

for (int i = 0; i < n; i++) cin >> a[i];     // ввод
for (int i = 0; i < n; i++) cout << a[i] << " ";   // вывод
```
- Размер массива в Builder 6 — **только константа**. `int a[n]` с переменной n — ошибка E2313. Объявляют «с запасом» `int a[100]` и вводят n ≤ 100.
- Выход за границы (a[10] у массива из 10) компилятор **не проверяет** — программа читает «мусор» или падает.
- **Типовые алгоритмы:** сумма (`s += a[i]`), среднее (s / n), максимум/минимум (запомнить первый и сравнивать), количество по условию, поиск первого подходящего (break), обмен `t = a[i]; a[i] = a[j]; a[j] = t;`, сдвиг, сортировка.
- **Сортировка** — упорядочивание элементов. Пузырьком: сравниваем соседей и меняем, если стоят неправильно; повторяем n−1 раз.
- **Плюсы массивов:** много значений под одним именем, обработка в цикле, быстрый доступ по индексу. **Минусы:** фиксированный размер, один тип, нет проверки границ.
```
for (int i = 0; i < n - 1; i++)          // сортировка пузырьком по возрастанию
  for (int j = 0; j < n - 1 - i; j++)
    if (a[j] > a[j + 1]) { int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t; }
```

## Двумерные массивы (матрицы)
! Дополнение: матрицы
Массив с двумя индексами — **матрица**, таблица из строк и столбцов: `int m[3][4];` — 3 строки по 4 элемента. `m[i][j]` — строка i, столбец j.
```
int m[2][3] = {{1, 2, 3}, {4, 5, 6}};    // по строкам
for (int i = 0; i < 2; i++)              // внешний цикл — строки
{
  for (int j = 0; j < 3; j++)            // внутренний — столбцы
    cout << m[i][j] << "\t";
  cout << endl;                          // после строки — перевод строки
}
```
- **Главная диагональ**: i == j (a[i][i]); **ниже** неё j < i, **выше** j > i; **побочная**: j == n−1−i.
- Сумма строки — внутренний цикл по j при фиксированном i; сумма столбца — наоборот.
- В памяти матрица лежит построчно, сплошным куском.
- Передать в функцию: `void f(int m[][4], int rows)` — второй размер обязателен.

## Конспект по вопросам УМКД
Коротко по каждому вопросу УМКД — на эти разделы ссылаются тесты.

## Что такое цикл с предусловием?
**Ответ из УМКД:** Цикл, условие которого проверяется перед телом:
while (условие) тело;
. Может не выполниться ни разу.
`while (условие) { тело }` — условие проверяется **до** тела. Если сразу ложно — тело не выполнится ни разу. Цикл заканчивается, когда условие стало **не истинным**.
Считаем повторы: `x=7; while(x<10){…x++;}` → 7, 8, 9 — 3 раза; с `<=10` — 4 раза; `x=2; while(x<10){…x=x+2;}` → 2,4,6,8 — 4 раза.

## Что такое цикл с постусловием?
**Ответ из УМКД:** Цикл, условие которого проверяется после тела:
do тело while (условие);
. Выполняется хотя бы один раз.
`do { тело } while (условие);` — условие проверяется **после** тела, поэтому тело выполнится хотя бы один раз. В ключе теста: цикл, который «заканчивается, когда условие истинно», — do-while (запомни пару: «истинно → do-while», «не истинно → while»).

## Разница между while и do…while?
**Ответ из УМКД:** while проверяет условие до тела (0 и более повторов), do…while — после (1 и более).
В C/C++ три вида циклов: `for`, `while`, `do…while`. `while` — 0 и более повторов, `do…while` — 1 и более. `repeat…until` — цикл Pascal, в C++ его нет.

## Когда уместно использовать while?
**Ответ из УМКД:** Когда число повторов неизвестно и может быть нулевым: обработка до признака конца, разбор цифр числа.
while — когда число повторов заранее неизвестно: «вводить, пока не введут 0», «разбирать число на цифры, пока оно не 0»:
```
while (n > 0) { s += n % 10; k++; n /= 10; }   // сумма и количество цифр
```

## Когда уместно использовать do…while?
**Ответ из УМКД:** Когда действие нужно выполнить хотя бы раз: ввод с проверкой, меню.
do…while — когда действие нужно хотя бы раз: ввод с проверкой.
```
do { cout << "Введите 1..10: "; cin >> x; } while (x < 1 || x > 10);
```

## Назначение break и continue?
**Ответ из УМКД:** break — досрочный выход из цикла (и switch); continue — переход к следующему повтору цикла.
`break` — досрочно выйти из цикла (и из switch). `continue` — пропустить остаток тела и перейти к следующему повтору.
```
for (i = 0; i < 10; i++) { cin >> x;
  if (x == 0) break;        // встретили 0 — стоп
  if (x < 0) continue;      // отрицательные пропускаем
  s += x; }
```

## Что такое массив?
**Ответ из УМКД:** Последовательность элементов одного типа под общим именем, к элементам обращаются по индексу.
Массив — ряд пронумерованных ячеек **одного типа** под одним именем: `a[0], a[1], …`. Элементы связаны общим типом (значения у них разные).

## Как объявить и инициализировать одномерный массив?
**Ответ из УМКД:** int a[10];
,
int b[5] = {1, 2, 3};
(остальные 0),
int c[] = {4, 8};
. Размер — константа.
```
int a[10];               // 10 целых, индексы 0..9
float b[10];             // 10 вещественных
int c[5] = {1, 2, 3};    // остальные станут 0
int d[] = {4, 8};        // размер посчитается сам (2)
```
Размер — в **квадратных** скобках и должен быть константой. Запись `a(10)` или `a[1..10]` — синтаксис Pascal, ошибка.

## Как обратиться к элементам массива?
**Ответ из УМКД:** По индексу в квадратных скобках:
a[0]
— первый,
a[n-1]
— последний. Индексы с 0.
К элементу обращаются по **индексу** в квадратных скобках; нумерация **с 0**: первый `a[0]`, последний `a[n-1]`. Массив обрабатывают циклом:
```
for (i = 0; i < n; i++) cin >> a[i];
for (i = 0; i < n; i++) if (i % 2 == 0) s += a[i];   // элементы с чётными НОМЕРАМИ
```
Ловушка: `i%2` — чётность номера, `a[i]%2` — чётность значения. Упорядочить элементы — **сортировка**. Поиск min/max: запомнить первый элемент и сравнивать с остальными.

## Что такое двумерный массив?
**Ответ из УМКД:** Массив с двумя индексами — таблица (матрица) из строк и столбцов:
int m[3][4];
Двумерный массив — **матрица** (таблица): `int m[3][4];` — 3 строки, 4 столбца, элемент `m[i][j]` (i — строка, j — столбец).
Главная диагональ — где `i == j` (`a[i][i]`); ниже неё — `j < i`; выше — `j > i`; побочная — `i + j == n-1`.

## Как объявить и инициализировать двумерный массив?
**Ответ из УМКД:** int m[2][3] = {{1,2,3},{4,5,6}};
или списком подряд
{1,2,3,4,5,6}
.
```
int m[2][3] = {{1,2,3},{4,5,6}};   // по строкам
int k[2][3] = {1,2,3,4,5,6};       // то же подряд
for (i=0;i<5;i++) for (j=0;j<5;j++) A[i][j] = (i+10)*j;   // по формуле
```

## Как вложенные циклы обрабатывают двумерный массив?
**Ответ из УМКД:** Внешний цикл перебирает строки, внутренний — столбцы:
for(i…) for(j…) m[i][j]
.
Внешний цикл — строки, внутренний — столбцы:
```
for (i = 0; i < n; i++)
  for (j = 0; j < m; j++)
    if (j < i) s += a[i][j];      // сумма ниже главной диагонали
```
Так же: сумма строки, сложение матриц `c[i][j]=a[i][j]+b[i][j]`, умножение (третий цикл по k), перенос в одномерный `b[i*m+j]=a[i][j]`.

## Плюсы и ограничения массивов?
**Ответ из УМКД:** Плюсы: много однотипных данных под одним именем, обработка в цикле, быстрый доступ по индексу. Ограничения: фиксированный размер (константа), один тип, нет проверки выхода за границы.
Плюсы: много однотипных данных под одним именем, обработка циклом, быстрый доступ по индексу. Ограничения: размер фиксирован, тип один, выход за границы не проверяется (a[10] у массива из 10 — ошибка, которую компилятор не заметит).

## Дополнение: поиск в массиве
Этот раздел дописан к лекции, чтобы пункт плана УМКД «поиск и сортировка элементов массива» был разобран полностью.
**Линейный поиск** — просматриваем элементы по порядку, пока не найдём нужный. Если нашли — запоминаем номер и выходим из цикла через break. Если цикл дошёл до конца — элемента нет.
```
int a[8] = {5, 12, 7, 3, 12, 9, 1, 4};
int x = 12, pos = -1;                 // -1 — «пока не нашли»
for (int i = 0; i < 8; i++)
  if (a[i] == x) { pos = i; break; }  // первый подходящий — выходим
if (pos >= 0) cout << "Found at " << pos;   // напечатает 1 (нумерация с 0)
else cout << "Not found";
```
**Максимум и его номер.** Запоминаем первый элемент как «лучший», остальные сравниваем с ним:
```
int imax = 0;
for (int i = 1; i < 8; i++)
  if (a[i] > a[imax]) imax = i;       // нашли больше — запомнили номер
cout << a[imax] << " at " << imax;    // 12 at 1
```
**Сортировка** — упорядочивание элементов (по возрастанию или убыванию). Пузырьком: соседние элементы сравниваются и меняются местами, пока массив не станет упорядоченным (код — в разделе «4. Одномерные массивы»). В отсортированном массиве можно искать быстрее — двоичным поиском: смотрим середину и отбрасываем ту половину, где элемента быть не может.
