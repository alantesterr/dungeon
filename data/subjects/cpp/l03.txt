## Условный оператор if
! Дополнение: if
**Условный оператор** выбирает, какое действие выполнить, в зависимости от условия. Это **оператор ветвления**: алгоритм делится на несколько путей.
```
if (условие) оператор;                       // сокращённая форма

if (условие) оператор1;                      // полная форма
else оператор2;

if (x > 0) { cout << "плюс"; k++; }         // несколько операторов — в { }
else if (x < 0) cout << "минус";             // цепочка проверок
else cout << "ноль";
```
- Условие — в круглых скобках, любое выражение: 0 — ложь, не 0 — истина.
- **Вложенный if** — if внутри другого if. `else` относится к **ближайшему** if без else; чтобы не путаться — ставь { }.
- Ошибка: точка с запятой после условия `if (x > 0);` — тогда if управляет пустым оператором, а следующая строка выполняется всегда.
- Ошибка: `if (x = 5)` вместо `if (x == 5)`.

## Множественный выбор switch
! Дополнение: switch
```
switch (выражение)          // целое число или символ
{
  case 1:  cout << "один"; break;
  case 2:
  case 3:  cout << "два или три"; break;
  default: cout << "другое";     // если не подошёл ни один case
}
```
- `case` — метка-значение, `default` — «во всех остальных случаях» (необязательна).
- `break` — выход из switch. **Без break выполнение «проваливается»** в следующий case: при n=45 в `case 45: cout<<"bbb"; default: cout<<"vvv";` напечатается bbbvvv.
- **Ограничения:** выражение только целое или char (не double, не string); в case — только константы, без диапазонов и условий.
- **if или switch?** switch удобен, когда сравниваем одну переменную с набором точных значений (меню, номер дня). if — для диапазонов и сложных условий (x > 0 && y < 5).

## Оператор goto
! Дополнение: goto и метки
**goto метка;** — безусловный переход к строке, отмеченной `метка:` в той же функции. Метка — идентификатор с двоеточием.
```
vvod:
  cout << "Оценка (1..5): "; cin >> m;
  if (m < 1 || m > 5) goto vvod;    // повторить ввод
```
goto делает программу запутанной («спагетти-код»), поэтому вместо него обычно пишут циклы. Но знать его нужно — он есть в теме УМКД.

## Цикл со счётчиком for
! Дополнение: for
```
for (инициализация; условие; изменение)
  тело;

for (int i = 1; i <= 10; i++)     // i = 1, 2, …, 10 — 10 раз
  cout << i << " ";
```
1. **Инициализация** выполняется один раз в начале (обычно счётчику даётся начальное значение).
2. **Условие** проверяется перед каждым повтором; ложно — цикл заканчивается.
3. Выполняется **тело**.
4. **Изменение** счётчика (`i++`, `i+=2`, `i--`), и снова проверка условия.
**Сколько раз?** `for(x=1; x<=10; x=x+2)` — x = 1,3,5,7,9 → 5 раз. `for(i=100; i>0; i-=10)` — 100, 90, …, 10. Счётчик можно уменьшать, менять на любой шаг, он может быть char: `for(char c='a'; c<='z'; c++)`.
**Вложенные циклы** — цикл внутри цикла: на каждый шаг внешнего внутренний выполняется полностью. Нужны для таблиц, матриц, «звёздочек».
**Бесконечный цикл** бывает, если условие никогда не станет ложным: `for(i=1; i>0; i++)`, `for(;;)`, или если счётчик меняется не в ту сторону. Выйти из такого цикла можно `break`.
**Управление внутри цикла:** `break` — сразу выйти из цикла, `continue` — перейти к следующему повтору (подробно в теме 4).

## Что такое условный оператор и зачем он нужен?
**Ответ из УМКД:** Оператор, который выполняет действие только при выполнении условия (или выбирает одно из двух). Нужен для разветвляющихся алгоритмов.
Условный оператор `if` («если») выполняет действие только когда условие истинно — алгоритм **разветвляется** на несколько путей. Без него программа шла бы всегда одной дорогой.
```
if (x > y) max = x; else max = y;   // выбрать большее из двух
```

## Синтаксис оператора if?
**Ответ из УМКД:** if (условие) оператор;
или
if (условие) оператор1; else оператор2;
Несколько операторов — в { }.
```
if (условие) оператор;
if (условие) оператор1; else оператор2;
if (условие) { несколько; операторов; }
```
Условие — в круглых скобках. Несколько действий — в фигурных скобках, иначе к if относится только первое. Условие «точка в прямоугольнике»: `x >= x1 && x <= x2 && y <= y1 && y >= y2`.

## Разница между if, if…else и вложенным if?
**Ответ из УМКД:** if — действие только при истинном условии; if…else — одно из двух действий; вложенный if — проверка внутри другой проверки, позволяет выбрать из нескольких вариантов.
`if` — сделать или нет; `if…else` — одно из двух; вложенный `if` / цепочка `else if` — выбор из нескольких:
```
if (x > 0 && y > 0) k = 1;
else if (x < 0 && y > 0) k = 2;
else if (x < 0) k = 3; else k = 4;      // номер квадранта
```
Чётность: `i % 2 == 0` — чётное, `i % 2 == 1` — нечётное. Сравнение — двойное `==`; одинарное `=` внутри if — ошибка-ловушка.

## Назначение оператора switch?
**Ответ из УМКД:** Множественный выбор: сравнивает значение целого выражения или символа с набором констант case и выполняет нужную ветку.
`switch` («переключатель») — **оператор выбора**: сравнивает целое или символ с константами `case` и выполняет нужную ветку. Удобен для меню и точных значений: день недели по номеру, калькулятор по знаку `'+'`.

## Для чего case, break и default?
**Ответ из УМКД:** case — метка-вариант значения; break — выход из switch (без него выполнение идёт дальше); default — ветка «во всех остальных случаях».
```
switch (n) {
  case 1: cout << "Пн"; break;      // break — выйти из switch
  case 2: cout << "Вт"; break;
  default: cout << "Нет такого дня"; // все остальные случаи
}
```
**Без break** выполнение «проваливается» в следующие case: при n=45 в `case 45: cout<<"bbb"; default: cout<<"vvv";` напечатается `bbbvvv`.

## Главные отличия if и switch?
**Ответ из УМКД:** if проверяет любые условия и диапазоны; switch — только равенство одного целого/символьного выражения константам. switch нагляднее для меню и точных значений.
`if` проверяет любые условия и диапазоны (`x > 0 && x < 2`). `switch` — только равенство одного целого/символьного выражения константам. Для оценок 1–5 удобнее switch, для «0 < x < 2» — только if. Переход `goto метка;` существует, но им почти не пользуются.

## Что такое цикл со счётчиком?
**Ответ из УМКД:** Цикл, число повторов которого задаётся переменной-счётчиком, меняющейся от начального до конечного значения с шагом — for.
Цикл со счётчиком (с параметром) — `for`: число повторов задаёт переменная-счётчик от начального до конечного значения с шагом.
```
for (i = 1; i < 10; i += 2) cout << i;   // 1 3 5 7 9
```
После цикла счётчик уже «за границей»: `for(a=0;a<10;a++)` закончится при a = 10 (последнее выведенное — 9).

## Синтаксис и структура for?
**Ответ из УМКД:** for (инициализация; условие; изменение) тело;
— инициализация один раз, условие перед каждым повтором, изменение после тела.
`for (инициализация; условие; изменение) тело;` — инициализация один раз, условие перед каждым повтором, изменение после тела. Чтобы посчитать число повторов — выпиши значения счётчика: `for(x=1;x<=10;x=x+2)` → 1,3,5,7,9 → 5 раз.
Подсчёт с условием: `for(x=1;x<=10;x++) if(x%3==0) k++;` → 3, 6, 9 → k = 3. Суммы рядов: `s=1; p=1; for(i=1;i<=N;i++){ p*=A; s+=p; }`.

## Что такое выражения инициализации, условия и изменения в for?
**Ответ из УМКД:** Инициализация задаёт начальное значение счётчика (
i = 1
), условие решает, продолжать ли (
i <= n
), изменение меняет счётчик (
i++
).
Три части for: **инициализация** (i = 100), **условие** (i > 0), **изменение** (i -= 10). Шаг может быть любым и в любую сторону: `for(i=100;i>0;i-=10)` → 100, 90, …, 10; `for(i=100;i<=150;i+=10)` → 100, …, 150 (знак <= включает границу).

## Что такое вложенные циклы и когда их используют?
**Ответ из УМКД:** Цикл внутри цикла; внутренний полностью выполняется на каждом шаге внешнего. Для таблиц, матриц, перебора пар.
Вложенный цикл — цикл внутри цикла: внутренний проходит **полностью** на каждом шаге внешнего. Пример — факториал внутри суммы ряда: для каждого k считаем k! во внутреннем цикле. Часто можно обойтись одним циклом, накапливая произведение: `f *= i; s += 1.0/f;`.

## Как может возникнуть бесконечный цикл?
**Ответ из УМКД:** Если условие никогда не становится ложным: счётчик не меняется или меняется не в ту сторону, условие всегда истинно (
for(;;)
).
Бесконечный цикл — условие никогда не становится ложным: счётчик не меняется или меняется не в ту сторону, `for(;;)`, `while(1)`. Циклы «пока сумма не превысит A» или «пока разница больше D» обязательно должны менять переменную условия, иначе зависнут.
