## 1. Условный оператор if
**If**

Условный оператор выбирает, какое действие выполнить, в зависимости от условия. Это оператор ветвления: алгоритм делится на несколько путей.

if (условие) оператор;                       // сокращённая форма

if (условие) оператор1;                      // полная форма
else оператор2;

```
if (x > 0) { cout << "плюс"; k++; }         // несколько операторов — в { }
else if (x < 0) cout << "минус";             // цепочка проверок
else cout << "ноль";
```
Условие — в круглых скобках, любое выражение: 0 — ложь, не 0 — истина.
Вложенный if — if внутри другого if. else относится к ближайшему if без else; чтобы не путаться — ставь { }.
Ошибка: точка с запятой после условия if (x > 0); — тогда if управляет пустым оператором, а следующая строка выполняется всегда.
Ошибка: if (x = 5) вместо if (x == 5).

! Вопрос УМКД: **Что такое условный оператор и зачем он нужен?** — Оператор, который выполняет действие только при выполнении условия (или выбирает одно из двух). Нужен для разветвляющихся алгоритмов.
! Вопрос УМКД: **Синтаксис оператора if?** — if (условие) оператор; или if (условие) оператор1; else оператор2; Несколько операторов — в { }.
! Вопрос УМКД: **Разница между if, if…else и вложенным if?** — if — действие только при истинном условии; if…else — одно из двух действий; вложенный if — проверка внутри другой проверки, позволяет выбрать из нескольких вариантов.

## 2. Множественный выбор switch
**Switch**
switch (выражение)          // целое число или символ
```
{
  case 1:  cout << "один"; break;
  case 2:
  case 3:  cout << "два или три"; break;
  default: cout << "другое";     // если не подошёл ни один case
}
```
case — метка-значение, default — «во всех остальных случаях» (необязательна).
break — выход из switch. Без break выполнение «проваливается» в следующий case: при n=45 в case 45: cout<<"bbb"; default: cout<<"vvv"; напечатается bbbvvv.
Ограничения: выражение только целое или char (не double, не string); в case — только константы, без диапазонов и условий.
if или switch? switch удобен, когда сравниваем одну переменную с набором точных значений (меню, номер дня). if — для диапазонов и сложных условий (x > 0 && y < 5).

! Вопрос УМКД: **Назначение оператора switch?** — Множественный выбор: сравнивает значение целого выражения или символа с набором констант case и выполняет нужную ветку.
! Вопрос УМКД: **Для чего case, break и default?** — case — метка-вариант значения; break — выход из switch (без него выполнение идёт дальше); default — ветка «во всех остальных случаях».
! Вопрос УМКД: **Главные отличия if и switch?** — if проверяет любые условия и диапазоны; switch — только равенство одного целого/символьного выражения константам. switch нагляднее для меню и точных значений.

## 3. Оператор goto
**Goto и метки**

goto метка; — безусловный переход к строке, отмеченной метка: в той же функции. Метка — идентификатор с двоеточием.

vvod:
```
  cout << "Оценка (1..5): "; cin >> m;
  if (m < 1 || m > 5) goto vvod;    // повторить ввод
```
goto делает программу запутанной («спагетти-код»), поэтому вместо него обычно пишут циклы. Но знать его нужно — он есть в теме УМКД.

## 4. Цикл со счётчиком for
**For**
for (инициализация; условие; изменение)
тело;

```
for (int i = 1; i <= 10; i++)     // i = 1, 2, …, 10 — 10 раз
  cout << i << " ";
```
Инициализация выполняется один раз в начале (обычно счётчику даётся начальное значение).
Условие проверяется перед каждым повтором; ложно — цикл заканчивается.
Выполняется тело.
Изменение счётчика (i++, i+=2, i--), и снова проверка условия.

Сколько раз? for(x=1; x<=10; x=x+2) — x = 1,3,5,7,9 → 5 раз. for(i=100; i>0; i-=10) — 100, 90, …, 10. Счётчик можно уменьшать, менять на любой шаг, он может быть char: for(char c='a'; c<='z'; c++).

Вложенные циклы — цикл внутри цикла: на каждый шаг внешнего внутренний выполняется полностью. Нужны для таблиц, матриц, «звёздочек».

Бесконечный цикл бывает, если условие никогда не станет ложным: for(i=1; i>0; i++), for(;;), или если счётчик меняется не в ту сторону. Выйти из такого цикла можно break.

Управление внутри цикла: break — сразу выйти из цикла, continue — перейти к следующему повтору (подробно в теме 4).

! Вопрос УМКД: **Что такое цикл со счётчиком?** — Цикл, число повторов которого задаётся переменной-счётчиком, меняющейся от начального до конечного значения с шагом — for.
! Вопрос УМКД: **Синтаксис и структура for?** — for (инициализация; условие; изменение) тело; — инициализация один раз, условие перед каждым повтором, изменение после тела.
! Вопрос УМКД: **Что такое выражения инициализации, условия и изменения в for?** — Инициализация задаёт начальное значение счётчика (i = 1), условие решает, продолжать ли (i <= n), изменение меняет счётчик (i++).
! Вопрос УМКД: **Что такое вложенные циклы и когда их используют?** — Цикл внутри цикла; внутренний полностью выполняется на каждом шаге внешнего. Для таблиц, матриц, перебора пар.
! Вопрос УМКД: **Как может возникнуть бесконечный цикл?** — Если условие никогда не становится ложным: счётчик не меняется или меняется не в ту сторону, условие всегда истинно (for(;;)).
