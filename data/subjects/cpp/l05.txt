## 1. Что такое функция
**Функция**

Функция — именованная последовательность операций и описаний, которая выполняет определённое действие и может вернуть результат. Зачем: не повторять один и тот же код, разбить программу на понятные части (модули), отлаживать по частям.

тип_результата имя(тип1 параметр1, тип2 параметр2)   // заголовок
```
{                                                      // тело в { }
```
…
return значение;     // вернуть результат туда, откуда вызвали
```
}
int sqr(int x)         // определение
{
  return x * x;
}
```
…
```
int y = sqr(5);        // вызов: аргумент 5 → параметр x, результат 25
```
void в заголовке — функция ничего не возвращает; в ней можно написать return; без значения.
return выражение; — завершает функцию и возвращает значение выражения в оператор, который её вызвал.
Выполнение любой программы начинается с функции main().

## 2. Объявление, определение, прототип
**Прототип**

Определение — заголовок + тело. Объявление (прототип) — только заголовок с точкой с запятой: int sqr(int x); или int sqr(int);. Прототип сообщает компилятору имя функции, количество и типы аргументов и тип результата.

Если функция описана ниже main, а вызывается в main, перед main нужен прототип — иначе Builder выдаст «Call to undefined function». Если описана выше main — прототип не нужен.

```
int sqr(int);          // прототип
int main() { cout << sqr(4); return 0; }
int sqr(int x) { return x * x; }   // определение после main
```

## 3. Параметры и аргументы. По значению и по ссылке
**Параметры**

Параметры (формальные) — переменные в заголовке функции. Аргументы (фактические параметры) — значения, которые передают при вызове.

По значению (void f(int x)): функция получает копию. Меняет копию — оригинал не меняется.

По ссылке (void f(int &x)): параметр — второе имя той же переменной. Изменения внутри функции меняют оригинал. Передать можно только переменную, не число.

```
void swapV(int a, int b) { int t = a; a = b; b = t; }    // не работает: меняет копии
void swapR(int &a, int &b) { int t = a; a = b; b = t; }  // работает: меняет оригиналы
```
Когда по ссылке: функция должна изменить переменную; нужно вернуть несколько результатов (Frac(a,b,p,q) возвращает p и q); большой объект — чтобы не копировать.

Ссылка — второе имя переменной: int &r = x; — теперь r и x одно и то же.

const: void show(const int a[], int n), void print(const string &s) — функция не может изменить параметр (защита от случайной порчи данных, «запрет изменения исходного массива»).

## 4. Параметры по умолчанию, inline, перегрузка
**Дополнение**
По умолчанию: double area(double r, double pi = 3.14) — можно вызвать area(2). Параметры с умолчанием — только в конце списка.
inline: inline int twice(int x) { return 2*x; } — просьба к компилятору вставить тело функции прямо на место вызова (для маленьких функций, ускоряет).
Перегрузка — несколько функций с одним именем, но разными параметрами: int sum(int,int); int sum(int,int,int); double sum(double,double); Компилятор выбирает по аргументам.

## 5. Массивы как параметры
**Массив в функцию**
```
void input(int a[], int n)           // массив передаётся адресом —
{ for (int i = 0; i < n; i++) cin >> a[i]; }   // изменения видны в main
void show(const int a[], int n)      // const — показать, но не менять
{ for (int i = 0; i < n; i++) cout << a[i] << " "; }
int sumRow(int m[][4], int row) { … }   // у матрицы второй размер обязателен
```
Массив всегда передаётся по адресу (без копии), поэтому функция может его менять. Размер массива функция не знает — передают отдельным параметром n.

## 6. Локальные и глобальные переменные
**Область видимости**
Локальная — объявлена внутри функции или блока { }, известна только там; создаётся при входе, исчезает при выходе.
Глобальная — объявлена вне всех функций, видна во всех функциях ниже; живёт всю программу; изначально 0.
Если локальная и глобальная с одним именем, внутри функции «видна» локальная; к глобальной — ::имя.
static локальная — сохраняет значение между вызовами.

## 7. Рекурсия
**Рекурсия**

Рекурсия — функция вызывает сама себя. Обязательно нужно условие выхода (базовый случай), иначе — бесконечная рекурсия и переполнение стека (Stack overflow).

```
long fact(int n)
{
  if (n <= 1) return 1;          // базовый случай
  return n * fact(n - 1);         // шаг рекурсии
}
```
Виды: прямая (функция вызывает себя) и косвенная (A вызывает B, B вызывает A).

## Вопросы УМКД к теме 5 — с ответами
- **Что такое функция и зачем она нужна?** — Именованная часть программы, выполняющая определённое действие и, возможно, возвращающая результат. Нужна, чтобы не повторять код и делить программу на части.
- **Разница между объявлением и определением функции?** — Объявление (прототип) — только заголовок с ;, сообщает компилятору о функции. Определение — заголовок и тело { }.
- **Что такое прототип функции?** — Объявление функции без тела: тип результата, имя, типы параметров. Помогает компилятору проверить количество и тип аргументов.
- **Что такое параметры и аргументы?** — Параметры (формальные) — переменные в заголовке функции; аргументы (фактические) — значения, передаваемые при вызове.
- **Как вызывается функция?** — По имени со скобками и аргументами: y = sqr(5);, show(a, n);
- **Назначение оператора return?** — Завершает функцию и возвращает значение выражения в место вызова; в void-функции — просто выход (return;).
- **Что значит передача по значению?** — Функция получает копию аргумента; изменения копии не влияют на исходную переменную.
- **Что значит передача по ссылке?** — Параметр тип &имя становится вторым именем переменной-аргумента; изменения в функции меняют оригинал.
- **Разница между передачей по значению и по ссылке?** — По значению — копия, оригинал не меняется, можно передать выражение; по ссылке — работа с оригиналом, передать можно только переменную, нет копирования.
- **Когда передавать параметры по ссылке?** — Когда функция должна изменить переменную, вернуть несколько результатов или когда объект большой и копировать его невыгодно (тогда const &).
- **Что такое ссылка в C++?** — Другое имя (псевдоним) существующей переменной: int &r = x;
- **Как функция меняет исходную переменную через ссылку?** — Параметр объявлен как ссылка void inc(int &x) { x++; }; вызов inc(a); увеличит саму a.
