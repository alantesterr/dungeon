## Что такое функция
! Дополнение: функция
**Функция** — именованная последовательность операций и описаний, которая выполняет определённое действие и может вернуть результат. Зачем: не повторять один и тот же код, разбить программу на понятные части (модули), отлаживать по частям.
```
тип_результата имя(тип1 параметр1, тип2 параметр2)   // заголовок
{                                                      // тело в { }
  …
  return значение;     // вернуть результат туда, откуда вызвали
}

int sqr(int x)         // определение
{
  return x * x;
}
…
int y = sqr(5);        // вызов: аргумент 5 → параметр x, результат 25
```
- `void` в заголовке — функция **ничего не возвращает**; в ней можно написать `return;` без значения.
- `return выражение;` — завершает функцию и возвращает значение выражения в оператор, который её вызвал.
- Выполнение любой программы начинается с функции `main()`.

## Объявление, определение, прототип
! Дополнение: прототип
**Определение** — заголовок + тело. **Объявление (прототип)** — только заголовок с точкой с запятой: `int sqr(int x);` или `int sqr(int);`. Прототип сообщает компилятору имя функции, **количество и типы аргументов** и тип результата.
Если функция описана **ниже** main, а вызывается в main, перед main нужен прототип — иначе Builder выдаст «Call to undefined function». Если описана **выше** main — прототип не нужен.
```
int sqr(int);          // прототип
int main() { cout << sqr(4); return 0; }
int sqr(int x) { return x * x; }   // определение после main
```

## Параметры и аргументы. По значению и по ссылке
! Дополнение: параметры
**Параметры (формальные)** — переменные в заголовке функции. **Аргументы (фактические параметры)** — значения, которые передают при вызове.
**По значению** (`void f(int x)`): функция получает **копию**. Меняет копию — оригинал не меняется.
**По ссылке** (`void f(int &x)`): параметр — **второе имя** той же переменной. Изменения внутри функции меняют оригинал. Передать можно только переменную, не число.
```
void swapV(int a, int b) { int t = a; a = b; b = t; }    // не работает: меняет копии
void swapR(int &a, int &b) { int t = a; a = b; b = t; }  // работает: меняет оригиналы
```
**Когда по ссылке:** функция должна изменить переменную; нужно вернуть несколько результатов (Frac(a,b,p,q) возвращает p и q); большой объект — чтобы не копировать.
**Ссылка** — второе имя переменной: `int &r = x;` — теперь r и x одно и то же.
**const**: `void show(const int a[], int n)`, `void print(const string &s)` — функция не может изменить параметр (защита от случайной порчи данных, «запрет изменения исходного массива»).

## Параметры по умолчанию, inline, перегрузка
! Дополнение: Дополнение
- **По умолчанию:** `double area(double r, double pi = 3.14)` — можно вызвать `area(2)`. Параметры с умолчанием — только в конце списка.
- **inline**: `inline int twice(int x) { return 2*x; }` — просьба к компилятору вставить тело функции прямо на место вызова (для маленьких функций, ускоряет).
- **Перегрузка** — несколько функций с одним именем, но разными параметрами: `int sum(int,int); int sum(int,int,int); double sum(double,double);` Компилятор выбирает по аргументам.

## Массивы как параметры
! Дополнение: массив в функцию
```
void input(int a[], int n)           // массив передаётся адресом —
{ for (int i = 0; i < n; i++) cin >> a[i]; }   // изменения видны в main
void show(const int a[], int n)      // const — показать, но не менять
{ for (int i = 0; i < n; i++) cout << a[i] << " "; }
int sumRow(int m[][4], int row) { … }   // у матрицы второй размер обязателен
```
Массив **всегда** передаётся по адресу (без копии), поэтому функция может его менять. Размер массива функция не знает — передают отдельным параметром n.

## Локальные и глобальные переменные
! Дополнение: область видимости
- **Локальная** — объявлена внутри функции или блока { }, известна только там; создаётся при входе, исчезает при выходе.
- **Глобальная** — объявлена вне всех функций, видна во всех функциях ниже; живёт всю программу; изначально 0.
- Если локальная и глобальная с одним именем, внутри функции «видна» локальная; к глобальной — `::имя`.
- `static` локальная — сохраняет значение между вызовами.

## Рекурсия
! Дополнение: рекурсия
**Рекурсия** — функция вызывает сама себя. Обязательно нужно **условие выхода** (базовый случай), иначе — бесконечная рекурсия и переполнение стека (Stack overflow).
```
long fact(int n)
{
  if (n <= 1) return 1;          // базовый случай
  return n * fact(n - 1);         // шаг рекурсии
}
```
**Виды:** прямая (функция вызывает себя) и косвенная (A вызывает B, B вызывает A).

## Что такое функция и зачем она нужна?
**Ответ из УМКД:** Именованная часть программы, выполняющая определённое действие и, возможно, возвращающая результат. Нужна, чтобы не повторять код и делить программу на части.
Функция — именованный кусок программы, который делает одно действие и может вернуть результат. Нужна, чтобы не повторять код и делить программу на части. В C нет отдельных «процедур» — это тоже функции (типа void).
**Локальная** переменная объявлена внутри функции и видна только в ней; **глобальная** — вне всех функций и видна везде. Ещё: перегрузка (одно имя — разные параметры), параметры по умолчанию `int f(int x=5)`, `inline`.

## Разница между объявлением и определением функции?
**Ответ из УМКД:** Объявление (прототип) — только заголовок с
;
, сообщает компилятору о функции. Определение — заголовок и тело { }.
**Объявление** (прототип) — заголовок с точкой с запятой: `int sum(int, int);`. **Определение** — заголовок и тело. Если функция описана после main, перед main нужен прототип.

## Что такое прототип функции?
**Ответ из УМКД:** Объявление функции без тела: тип результата, имя, типы параметров. Помогает компилятору проверить количество и тип аргументов.
Прототип — объявление без тела: тип результата, имя, типы параметров. По нему компилятор проверяет **количество и типы аргументов** при вызове.
```
long fact(int n);                 // прототип
int main() { cout << fact(5); }
long fact(int n) { return n <= 1 ? 1 : n * fact(n - 1); }   // рекурсия
```

## Что такое параметры и аргументы?
**Ответ из УМКД:** Параметры (формальные) — переменные в заголовке функции; аргументы (фактические) — значения, передаваемые при вызове.
**Формальные** параметры — переменные в заголовке функции (заготовки). **Фактические** (аргументы) — значения, которые подставляют при вызове: в `max(3, y)` 3 и y — фактические.

## Как вызывается функция?
**Ответ из УМКД:** По имени со скобками и аргументами:
y = sqr(5);
,
show(a, n);
Вызов — имя и аргументы в скобках: `y = sqr(5);`, `show(a, n);`. Функция, которая вызывает сама себя, — **рекурсия** (обязательно нужен случай выхода, например n ≤ 1).

## Назначение оператора return?
**Ответ из УМКД:** Завершает функцию и возвращает значение выражения в место вызова; в void-функции — просто выход (
return;
).
`return выражение;` завершает функцию и отдаёт значение туда, где её вызвали. `void` в заголовке — функция ничего не возвращает; в ней пишут просто `return;`.
```
int m(int x, int y) { if (x < y) return x; else return y; }   // меньшее из двух
```

## Что значит передача по значению?
**Ответ из УМКД:** Функция получает копию аргумента; изменения копии не влияют на исходную переменную.
По значению функция получает **копию**: `int inc2(int vv){ vv++; return vv; }` — при `a = inc2(b)` с b=5 получаем a=6, а b остаётся 5.

## Что значит передача по ссылке?
**Ответ из УМКД:** Параметр
тип &имя
становится вторым именем переменной-аргумента; изменения в функции меняют оригинал.
По ссылке параметр — `тип &имя`: это второе имя самой переменной, изменения в функции меняют оригинал.
```
void swapR(int &a, int &b) { int t = a; a = b; b = t; }   // меняет местами по-настоящему
```

## Разница между передачей по значению и по ссылке?
**Ответ из УМКД:** По значению — копия, оригинал не меняется, можно передать выражение; по ссылке — работа с оригиналом, передать можно только переменную, нет копирования.
По значению — копия, оригинал не меняется, можно передать выражение (`f(x+1)`). По ссылке — работа с оригиналом, передать можно только переменную. Через ссылки функция может «вернуть» несколько результатов: `Frac(a,b,p,q)` кладёт ответ в p и q.

## Когда передавать параметры по ссылке?
**Ответ из УМКД:** Когда функция должна изменить переменную, вернуть несколько результатов или когда объект большой и копировать его невыгодно (тогда
const &
).
По ссылке передают, когда функция должна изменить переменную, вернуть несколько результатов или когда объект большой (тогда `const тип &` — без копии и без права менять). Массив в функцию всегда передаётся как адрес — функция меняет сам массив.

## Что такое ссылка в C++?
**Ответ из УМКД:** Другое имя (псевдоним) существующей переменной:
int &r = x;
Ссылка — другое имя (псевдоним) существующей переменной: `int &r = x;` — теперь r и x одно и то же.

## Как функция меняет исходную переменную через ссылку?
**Ответ из УМКД:** Параметр объявлен как ссылка
void inc(int &x) { x++; }
; вызов
inc(a);
увеличит саму a.
`void inc(int &x) { x++; }` — вызов `inc(a);` увеличит саму a, потому что x — её второе имя.
