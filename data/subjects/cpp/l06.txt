## Тип char
! Дополнение: символ
**char** — тип для одного символа, 1 байт. В памяти хранится не буква, а её **код** — целое число (таблица ASCII, для русских букв в Windows — кодировка 1251). Поэтому с char можно считать как с числом:
```
char c = 'A';            // символьная константа — в одинарных кавычках
cout << c;               // A
cout << (int)c;          // 65 — код
cout << c + 1;           // 66 — в выражении char становится int
cout << (char)(c + 1);   // B
char d = '7'; int n = d - '0';   // n = 7 — цифра-символ в число
```
- Коды: '0'…'9' = 48…57, 'A'…'Z' = 65…90, 'a'…'z' = 97…122. Маленькая буква = большая + 32.
- Диапазон char в Builder: −128…127 (русские буквы имеют отрицательные коды: (int)'Я' = −33).
- Escape-последовательности — тоже символы: '\n', '\t', '\\', '\'', '\0'.
- ctype.h: `isdigit, isalpha, isspace, isupper, islower, toupper, tolower` (с латиницей).

## Строка как массив char
! Дополнение: C-строка
**Символ и строка — разные вещи.** `'A'` — один символ (1 байт). `"A"` — строка: 2 байта, 'A' и **нулевой символ '\0'**, которым заканчивается любая строка.
```
char s[20] = "Hello";     // 'H','e','l','l','o','\0', остальное — нули
char t[] = "abc";         // размер 4 (3 буквы + '\0')
cout << s;                // выводится до '\0'
cin >> s;                 // читает одно СЛОВО (до пробела)
cin.getline(s, 20);       // читает всю строку с пробелами (максимум 19 символов)
gets(s);                  // то же из stdio.h
s[0] = 'J';               // доступ к символу по индексу
```
**Функции string.h** (их много в тестах — запоминай по английскому корню):
| Функция | Что делает |
| `strlen(s)` | длина (без '\0'), length |
| `strcpy(s1, s2)` | копирует s2 в s1, copy. Присвоить `s1 = s2` нельзя! |
| `strncpy(s1, s2, k)` | копирует первые k символов |
| `strcat(s1, s2)` | дописывает s2 в конец s1, concatenate |
| `strncat(s1, s2, k)` | дописывает первые k символов s2 |
| `strcmp(s1, s2)` | сравнивает: 0 — равны, <0 — s1 раньше по алфавиту, >0 — позже, compare |
| `strncmp(s1, s2, k)` | сравнивает первые k символов |
| `stricmp(s1, s2)` | сравнивает без учёта регистра, ignore case |
| `strchr(s, ch)` | ищет символ слева направо, возвращает указатель на него или NULL |
| `strrchr(s, ch)` | ищет символ справа налево (с конца), reverse |
| `strstr(s1, s2)` | ищет строку s2 внутри s1 |
| `strrev(s)` | переворачивает строку |
| `strupr(s)`, `strlwr(s)` | в верхний / нижний регистр (upper / lower) |
| `strset(s, ch)`, `strnset(s, ch, k)` | заполняет символом ch всю строку / первые k символов |
**Типичные ошибки:** забыть место под '\0' (`char s[5] = "Hello"` — не влезет); сравнивать строки через `==` (сравниваются адреса, а не текст — нужен strcmp); присваивать `s = "текст"` вместо strcpy; читать фразу через `cin >>` (берёт только первое слово); после `cin >> n` сразу `getline` — получит пустую строку (нужен `cin.ignore()`).

## Класс string
! Дополнение: string
`string` (подключить `<string>` и `using namespace std;`) — строка-объект: сама следит за размером, присваивается через `=`, сравнивается через `==`, склеивается через `+`.
```
string a = "Hello", b;
b = a + ", World";              // соединение
if (a == "Hello") …             // сравнение: == != < >
a.length()  a.size()            // длина
a[0]  a.at(0)                   // символ
a.substr(7, 5)                  // подстрока: с позиции 7, 5 символов
a.find("lo")                    // позиция подстроки или string::npos (не нашли)
a.insert(5, "!!")  a.erase(0, 2)  a.replace(0, 1, "J")
getline(cin, a);                // ввести строку с пробелами
a.c_str()                       // как char* — для printf и strcpy
```
| Действие | char[] | string |
| присвоить | `strcpy(s, "abc")` | `s = "abc"` |
| соединить | `strcat(s, t)` | `s + t`, `s += t` |
| сравнить | `strcmp(s, t) == 0` | `s == t` |
| длина | `strlen(s)` | `s.length()` |
| ввод строки | `cin.getline(s, 80)` | `getline(cin, s)` |
| размер | фиксированный, нужно следить | растёт сам |

## Конспект по вопросам УМКД
Коротко по каждому вопросу УМКД — на эти разделы ссылаются тесты.

## Что такое тип char?
**Ответ из УМКД:** Символьный тип, 1 байт; хранит код одного символа (−128…127 в Builder).
`char` — символьный тип, 1 байт, хранит **код** одного символа (−128…127). Символ пишут в одинарных кавычках: `'A'`.

## Как символ представлен и хранится в памяти?
**Ответ из УМКД:** Как целое число — код символа в таблице ASCII / Windows-1251: 'A' = 65, '0' = 48.
В памяти символ — это число из таблицы кодов (ASCII / Windows-1251): `'A' = 65`, `'a' = 97`, `'0' = 48`. Поэтому с символами можно считать: `(int)c` — код, `c + 1` — следующая буква (шифр Цезаря).

## Разница между символом и строкой?
**Ответ из УМКД:** Символ 'A' — одно значение char (1 байт); строка "A" — массив символов, заканчивается '\0' (2 байта).
Символ `'A'` — одно значение char (1 байт). Строка `"A"` — массив символов с невидимым `'\0'` в конце (2 байта). Регистр важен: `'a' != 'A'`; сравнить без учёта регистра — `stricmp` (i = ignore case).

## Для чего нужны escape-последовательности при работе с символами?
**Ответ из УМКД:** Чтобы записать особые символы: '\n' (новая строка), '\t', '\\', '\'', '\0' (конец строки).
Escape-последовательности записывают особые символы через `\`: `'\n'` новая строка, `'\t'` табуляция, `'\\'` сама косая черта, `'\''` кавычка, `'\0'` — конец строки.

## Что такое строка в C++?
**Ответ из УМКД:** Последовательность символов: массив char с '\0' в конце (C-строка) или объект класса string.
Строка — последовательность символов. В C это массив `char` с `'\0'` в конце (C-строка), в C++ ещё есть класс `string`.

## Что такое класс string?
**Ответ из УМКД:** Класс стандартной библиотеки C++ для строк: сам управляет памятью, поддерживает =, +, ==, методы length, substr, find, insert, erase.
`string` (из `<string>`) сам управляет памятью: `s = "abc"`, `s1 + s2`, `==`, `s.length()`, `s.substr()`, `s.find()`. А `string.h` — это библиотека **функций для C-строк** (strlen, strcpy…), не путать.

## Как объявить и инициализировать строку?
**Ответ из УМКД:** char s[20] = "Hello";
,
char t[] = "abc";
,
string u = "World";
```
char s[20] = "Hello";   // место на 19 символов + '\0'
char t[] = "abc";       // размер 4 посчитается сам
string u = "World";     // класс string
```

## Как ввести и вывести строку?
**Ответ из УМКД:** Вывод —
cout << s
. Ввод слова —
cin >> s
; строки с пробелами —
cin.getline(s, n)
,
gets(s)
или
getline(cin, str)
.
Вывод — `cout << s`. Ввод одного слова — `cin >> s` (до пробела). Строку с пробелами — `cin.getline(s, 80)`, `gets(s)` или `getline(cin, str)`. Проверка символов — `ctype.h`: `isalpha`, `isdigit`, `isspace`.

## Как соединить две строки?
**Ответ из УМКД:** char[]:
strcat(s1, s2)
; string:
s1 + s2
или
s1 += s2
.
Соединить (concatenate): `strcat(s1, s2)` дописывает s2 в конец s1 (результат в s1); `strncat(s1, s2, k)` — только первые k символов s2. Для string — `s1 + s2` или `s1 += s2`.

## Как сравнить строки?
**Ответ из УМКД:** char[]:
strcmp(s1, s2)
(0 — равны); string:
==, !=, <, >
.
`strcmp(s1, s2)` (compare) возвращает **0, если строки равны**, меньше 0 — если s1 «раньше по алфавиту», больше 0 — если позже. `strncmp(s1,s2,k)` — сравнить только первые k символов; `stricmp` — без учёта регистра. Для string — `==`, `<`.

## Как определить длину строки?
**Ответ из УМКД:** strlen(s)
для char[] (без '\0');
s.length()
или
s.size()
для string.
`strlen(s)` (length) — число символов **без** `'\0'`: `strlen("jack") = 4`. Для string — `s.length()`. Все str-функции — в `string.h`.

## Какие основные операции со строками?
**Ответ из УМКД:** Копирование, соединение, сравнение, длина, поиск символа и подстроки, вставка, удаление, замена, перевод регистра, разворот.
| Функция | Что делает | Как запомнить |
| `strcpy(a,b)` | копирует b в a | cpy = copy |
| `strncpy(a,b,k)` | первые k символов b в a | n = «не больше k» |
| `strnset(s,ch,k)` | первые k символов s заменить на ch | set = установить |
| `strchr(s,ch)` | найти символ слева направо | chr = char |
| `strrchr(s,ch)` | найти символ с конца | лишняя r = reverse |
| `strstr(a,b)` | найти строку b внутри a | строка в строке |
| `strupr / strlwr` | в ЗАГЛАВНЫЕ / в строчные | upper / lower |
| `strrev(s)` | перевернуть строку | rev = reverse |
