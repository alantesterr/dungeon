#1
Ответ: Class (класс) — набор данных (полей) и методов для работы с этими данными.
Почему не другие: property — одно свойство, form — окно программы, event — событие, type — общее слово «тип».
По лекции: тема 7, раздел «2. Класс, объект, атрибут, метод».
#2
Ответ: encapsulation (инкапсуляция) — механизм, который связывает вместе код и данные, с которыми он работает, и защищает их от внешнего доступа.
По лекции: тема 7, разделы «3. Четыре принципа ООП» и «Для теста на английском».
#3
Ответ: object (объект) — экземпляр класса в памяти.
Ловушка: класс — только описание (тип), памяти под данные у него нет; объект создаётся по классу.
По лекции: тема 7, раздел «2. Класс, объект, атрибут, метод».
#4
Ответ: inheritance (наследование) — производный класс получает свойства базового (родительского) класса.
По лекции: тема 7, раздел «3. Четыре принципа ООП».
#5
Ответ: method (метод) — функция класса, которая задаёт поведение объекта (операции над его данными).
Почему не другие: property — данные, event — событие, show() — просто один из возможных методов.
По лекции: тема 7, раздел «2. Класс, объект, атрибут, метод».
#6
Ответ: encapsulation — защищает данные объекта от произвольного доступа внешнего кода (private-поля + методы доступа).
По лекции: тема 7, раздел «3. Четыре принципа ООП».
#7
Ответ: property (свойство, атрибут) — переменная, которая описывает внутреннее состояние объекта.
Почему не другие: method — действие, event — событие, polymorphism и inheritance — принципы.
По лекции: тема 7, раздел «2. Класс, объект, атрибут, метод».
#8
Ответ: polymorphism (полиморфизм) — «один интерфейс, много реализаций»: одно имя действия для общего класса действий.
По лекции: тема 7, раздел «3. Четыре принципа ООП».
#9
Ответ: Event (событие) — сообщение операционной системы приложению о том, что произошло внешнее действие (щелчок, нажатие клавиши).
Ловушка: Event handler — это функция-обработчик, которая реагирует на событие, а не само сообщение.
По лекции: тема 7, раздел «Для теста на английском», и тема 11.
#10
Ответ: compiler (компилятор) — по ключу базы.
Точнее: для перегруженных функций нужный вариант выбирает компилятор (раннее связывание), а для virtual-методов — программа во время работы (позднее связывание). На экзамене выбирай compiler.
По лекции: тема 7, раздел «3. Четыре принципа ООП», тема 12 (виртуальные методы).
#11
Ответ: class — описание формата данных и доступных функций для данного типа.
По лекции: тема 7, раздел «2. Класс, объект, атрибут, метод».
#12
Ответ: objects (объекты) — экземпляры классов, переменные типа, определённого классом.
По лекции: тема 7, раздел «2. Класс, объект, атрибут, метод».
#13
Ответ: method — функция, связанная с классом.
По лекции: тема 7, раздел «2. Класс, объект, атрибут, метод».
#14
Ответ: method — действие, которое объект умеет выполнять.
Почему не другие: event — то, что с объектом произошло, property — его характеристика.
По лекции: тема 7, раздел «Для теста на английском».
#15
Ответ: Encapsulation — внутреннее устройство объекта скрыто от взгляда снаружи; доступ только через открытый интерфейс.
Ловушка: абстракция — выделение главного (модель предмета), а скрытие деталей — инкапсуляция.
По лекции: тема 7, раздел «3. Четыре принципа ООП».
#16
Ответ: Abstraction (абстракция) — модель, «вид» реального предмета, в которой оставлено только важное для задачи.
По лекции: тема 7, раздел «3. Четыре принципа ООП».
#17
Ответ: Inheritance — позволяет использовать атрибуты и поведение уже существующих классов.
По лекции: тема 7, раздел «3. Четыре принципа ООП».
#18
Ответ: Polymorphism — одни и те же имена для разной функциональности (например, метод draw() у круга и у квадрата рисует по-разному).
По лекции: тема 7, раздел «3. Четыре принципа ООП».
