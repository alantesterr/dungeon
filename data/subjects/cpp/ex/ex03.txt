#1
Ответ: switch — оператор множественного выбора: switch (n) { case 1: …; break; default: … }.
Почему не другие: if — условный оператор, for — цикл, return — возврат из функции, class — описание класса.
По лекции: тема 3, раздел «2. Множественный выбор switch».
#2
Ответ: break — выход из switch (и из цикла).
Почему не другие: case — метка варианта, default — ветка «иначе», return выходит из всей функции, do — начало цикла.
По лекции: тема 3, раздел «2. Множественный выбор switch».
