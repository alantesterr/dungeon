#1
Ответ: идентификатор — это имя объекта программы (переменной, константы, функции, типа, класса).
Почему не другие: «слова для компилятора» — это ключевые слова, «массив» и «динамическая память» — совсем другие понятия.
По лекции: тема 1, раздел «6. Идентификаторы и ключевые слова».
#2
Ответ: main(). Выполнение любой программы на C/C++ начинается с функции main(), и она одна на программу.
Почему не другие: random/randomize() — функции случайных чисел, clrscr() — очистка экрана; их только вызывают из main.
По лекции: тема 1, раздел «8. Структура программы в Borland C++».
#3
Ответ: идентификатор — имя из латинских букв, цифр и _, которое начинается с буквы (или _), но не с цифры.
Почему не другие: константа — неизменяемое значение (25, 'A'), комментарий — текст для человека, функция — подпрограмма.
По лекции: тема 1, раздел «6. Идентификаторы и ключевые слова» — правила составления имён.
#4

Почему не другие: var и procedure — слова из Pascal, int — просто тип, а не «константа».
По лекции: тема 1, раздел «7. Константы, escape-последовательности, комментарии».
#5
Ответ: переменная — именованная область памяти, в которой хранится значение определённого типа.
Почему не другие: «выражение из операндов и знаков операций» — это определение выражения (тема 2), тип у переменной всегда определён.

#6
Ответ: #define задаёт значение константы (макрос): #define N 10 — перед компиляцией все N заменятся на 10.
Почему не другие: в этом тесте «правильным» считается именно «задать значение константы»; «выражение из операндов…» — определение выражения.
По лекции: тема 1, раздел «7. Константы…» — пример #define N 10.
#7
Ответ: переменная — величина, которая может принимать разные значения во время работы программы.
Это второе определение того же понятия: в отличие от константы, значение переменной меняется (x = 5; потом x = 7;).
По лекции: тема 1, раздел «Ввод-вывод и переменные».

Почему не другие: «a int;» — неверный порядок, integer — слово из Pascal, float и char — не целые типы.

#9
Ответ: { } — фигурные скобки. Тело функции (и любой блок операторов) заключается в них: int main() { … }.
Почему не другие: ( ) — для параметров, /* */ — комментарий, / / и * * не используются.
По лекции: тема 1, раздел «8. Структура программы в Borland C++».
#10
Ответ: /* … */ — многострочный комментарий в C (в C++ есть ещё // до конца строки).
Почему не другие: { } — тело функции, (* *) — комментарий в Pascal, < > — для #include.
По лекции: тема 1, раздел «7. Константы, escape-последовательности, комментарии».
#11
Ответ: лексема (token) — наименьшая смысловая единица языка, «слово» программы.
Например, строка sum = a + 15; состоит из 6 лексем: sum, =, a, +, 15, ;.
По лекции: тема 1, раздел «5. Алфавит C++ и лексемы».

По лекции: тема 1, раздел «9. Типы данных».
