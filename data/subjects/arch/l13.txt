## Адресное пространство и карта первого мегабайта

Адресное пространство — все адреса, которые может сформировать процессор: 2ᴺ при N-битной шине адреса. Его делят между ОЗУ, ПЗУ и устройствами. Классическая карта первого мегабайта IBM PC (реальный режим):

00000h–003FFh   1 КБ    таблица векторов прерываний (256 × 4 байта)
00400h–004FFh           область данных BIOS
00500h–9FFFFh   ≈640 КБ основная память (Conventional): DOS и программы
A0000h–BFFFFh   128 КБ  видеопамять (B8000h — текстовый экран цветного адаптера)
C0000h–EFFFFh           ПЗУ адаптеров (видео BIOS и др.), UMB
F0000h–FFFFFh   64 КБ   системный BIOS (ПЗУ); FFFF0h — точка старта процессора
100000h–10FFEFh ≈64 КБ  HMA (на 286+ при открытой линии A20)

Поэтому в тестах: в первом килобайте — таблица векторов прерываний; изображение на экране хранится в видео-ОЗУ.

! Вопрос УМКД: **Что такое адресное пространство компьютера?** — Адресное пространство — множество всех адресов, которые процессор может выставить на шину (2ᴺ).

## Логический и физический адрес, порты

Логический адрес формирует программа (сегмент:смещение или виртуальный адрес), физический — то, что выставляется на шину адреса. Преобразование делает процессор (сегментация) и MMU (страницы) — тема 12.

Устройства ввода-вывода подключаются двумя способами: отдельное пространство портов (x86: 65 536 портов, команды IN/OUT; например, 60h — клавиатура, 20h — контроллер прерываний) или отображение на память (memory-mapped I/O: регистры устройства занимают обычные адреса, работа командой MOV — так видеопамять и современные PCIe-устройства).

! Вопрос УМКД: **Чем логический адрес отличается от физического?** — Логический vs физический: логический формирует программа, физический — реальный адрес на шине после преобразования.
! Вопрос УМКД: **Что означает отображение устройств ввода-вывода в адресное пространство памяти?** — Отображение ввода-вывода в память — регистры устройств доступны по адресам памяти обычными командами.

## Ошибки и избыточность

Биты портятся: помехи в линиях связи, космические частицы и альфа-частицы в ячейках DRAM, утечки заряда, износ флеш-памяти. Чтобы их находить, к данным добавляют избыточные (проверочные) биты.

Расстояние Хэмминга между словами — число разрядов, в которых они различаются (1011 и 1110 → 2). Кодовое расстояние d — минимальное расстояние между разрешёнными кодовыми словами. Код обнаруживает до d − 1 ошибок и исправляет до ⌊(d − 1)/2⌋.

Бит чётности: d = 2 → обнаруживает 1 ошибку, не исправляет.
Код Хэмминга: d = 3 → исправляет 1 ошибку.
Хэмминг + общий бит чётности (ECC-память, SECDED): d = 4 → исправляет 1, обнаруживает 2.

! Вопрос УМКД: **Почему при хранении и передаче данных возникают ошибки?** — Причины ошибок: помехи, частицы, утечки заряда, износ носителей.
! Вопрос УМКД: **Что называется кодовым расстоянием?** — Кодовое расстояние — минимальное число различающихся разрядов между двумя разрешёнными кодовыми словами.

## Код Хэмминга по шагам (как решать тесты)
Сколько контрольных битов? Наименьшее r: 2ʳ ≥ m + r + 1 (m — бит данных). m = 4 → r = 3 (код 7,4); m = 5…11 → r = 4; m = 12…26 → r = 5.
Позиции нумеруются слева, с 1. Контрольные биты P стоят на позициях-степенях двойки: 1, 2, 4, 8…; данные заполняют остальные по порядку.
Каждый Pk проверяет позиции, у которых в двоичном номере есть бит k: P1 — 1, 3, 5, 7, 9, 11…; P2 — 2, 3, 6, 7, 10, 11…; P4 — 4–7, 12–15; P8 — 8–15.
Pk = XOR данных на своих позициях (чётность: сумма единиц в группе — чётная).
Проверка: пересчитай XOR каждой группы вместе с контрольным битом. Получится синдром S = S8 S4 S2 S1. S = 0 — ошибок нет, иначе S — номер ошибочной позиции.
Пример из базы: данные 10000 (m = 5 → r = 4, длина 9)
поз:   1  2  3  4  5  6  7  8  9
P1 P2 d  P4 d  d  d  P8 d
данные       1     0  0  0     0
P1 = d3⊕d5⊕d7⊕d9 = 1⊕0⊕0⊕0 = 1
P2 = d3⊕d6⊕d7    = 1⊕0⊕0   = 1
P4 = d5⊕d6⊕d7    = 0
P8 = d9          = 0
код: 1 1 1 0 0 0 0 0 0  → 111000000 ✔

! Вопрос УМКД: **Сколько проверочных битов требуется для кода Хэмминга (7,4)?** — Код (7,4) — 3 проверочных бита.
! Вопрос УМКД: **На каких позициях располагаются проверочные биты в стандартной схеме Хэмминга (7,4)?** — Позиции проверочных битов — 1, 2, 4 (степени двойки).
! Вопрос УМКД: **Как вычисляется синдром ошибки?** — Синдром — XOR каждой проверочной группы вместе с её контрольным битом; двоичное число из результатов.

! Вопрос УМКД: **Как код Хэмминга (7,4) позволяет исправить одиночную ошибку?** — Исправление: синдром ≠ 0 указывает номер ошибочного бита — его инвертируют.

## Задания СРО по УМКД
Задание: Изучить принципы распределения адресного пространства компьютера. Рассмотреть назначение корректирующих кодов. Для четырёхбитных информационных слов 1011 и 1101 построить код Хэмминга (7,4) с чётным контролем. Определить значения контрольных битов. Смоделировать ошибку в одном из разрядов кодового слова, вычислить синдром и восстановить исходные данные. Объяснить возможности и ограничения кода Хэмминга.
Форма отчётности: Расчётная работа с таблицами кодирования и исправления ошибок.

## Разбор заданий СРО (тема 13)
**Код Хэмминга (7,4) с чётным контролем.** 4 бита данных d1 d2 d3 d4 и 3 проверочных бита p1, p2, p4 на позициях-степенях двойки. Порядок позиций 1…7: p1 p2 d1 p4 d2 d3 d4.
- p1 контролирует позиции 1, 3, 5, 7: p1 = d1 ⊕ d2 ⊕ d4;
- p2 — позиции 2, 3, 6, 7: p2 = d1 ⊕ d3 ⊕ d4;
- p4 — позиции 4, 5, 6, 7: p4 = d2 ⊕ d3 ⊕ d4.
Чётный контроль: в каждой группе (вместе с проверочным битом) число единиц чётное.
**Слово 1011** (d1 = 1, d2 = 0, d3 = 1, d4 = 1): p1 = 1 ⊕ 0 ⊕ 1 = 0; p2 = 1 ⊕ 1 ⊕ 1 = 1; p4 = 0 ⊕ 1 ⊕ 1 = 0.
| Позиция | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| Бит | p1 | p2 | d1 | p4 | d2 | d3 | d4 |
| Значение | 0 | 1 | 1 | 0 | 0 | 1 | 1 |
Кодовое слово: **0110011**. Ошибка: пусть испортился бит 5 (0 → 1), приняли 0110111. Синдром: s1 = b1⊕b3⊕b5⊕b7 = 0⊕1⊕1⊕1 = 1; s2 = b2⊕b3⊕b6⊕b7 = 1⊕1⊕1⊕1 = 0; s4 = b4⊕b5⊕b6⊕b7 = 0⊕1⊕1⊕1 = 1. Синдром s4s2s1 = 101₂ = 5 — ошибка в позиции 5. Инвертируем её → 0110011, данные (позиции 3, 5, 6, 7) = 1011.
**Слово 1101** (d1 = 1, d2 = 1, d3 = 0, d4 = 1): p1 = 1 ⊕ 1 ⊕ 1 = 1; p2 = 1 ⊕ 0 ⊕ 1 = 0; p4 = 1 ⊕ 0 ⊕ 1 = 0.
| Позиция | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| Бит | p1 | p2 | d1 | p4 | d2 | d3 | d4 |
| Значение | 1 | 0 | 1 | 0 | 1 | 0 | 1 |
Кодовое слово: **1010101**. Ошибка в бите 3 (1 → 0): приняли 1000101. s1 = 1⊕0⊕1⊕1 = 1; s2 = 0⊕0⊕0⊕1 = 1; s4 = 0⊕1⊕0⊕1 = 0. Синдром 011₂ = 3 — исправляем бит 3 → 1010101, данные = 1101.
**Возможности и ограничения.** Минимальное кодовое расстояние кода (7,4) равно 3: он исправляет одну ошибку или обнаруживает две, но не может и то и другое сразу. Две ошибки дадут ненулевой синдром, указывающий на неверную позицию, — «исправление» испортит третий бит. Чтобы отличать одиночную ошибку от двойной, добавляют общий бит чётности (код 8,4 — SECDED, так работает память ECC). Цена: 3 лишних бита на 4 бита данных.
